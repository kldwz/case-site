## Startup Insights

- Value proposition: A hosted, symbol-level code knowledge graph that resolves relationships instead of guessing them, queryable by your agents over MCP and by your team over the web.
- Problem solved: Coding agents rewrite logic that already exists and break things they can't see. Local graph tools guess at ambiguous symbols and label the guess. doc0 resolves or declines, so what the agent reads is actually true.
- Pricing model: $0 for open source, $29/month Pro, $299/month Team.
