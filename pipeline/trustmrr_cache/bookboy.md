## Startup Insights

- Value proposition: turns any text-based pdf into a customizable audiobook on mac - choose the voice, listen while it generates, and keep everything locally.
- Problem solved: audiobooks can be expensive, unavailable for many pdfs, and limited to a fixed narrator. bookboy lets users listen to pdfs they already own in a voice they choose, without a subscription.
- Pricing model: $19
- Target persona: Book Readers. Hobbyists.
- Audience type: [B2C](https://trustmrr.com/search?targetAudience=B2C)
- Team size: 1 person
- Funding: Bootstrapped
- Estimated user count: 5
- Additional info: featured on the Product-Hunt. works Locally on any mac, no TTS API key needed.
- Markets: [AI](https://trustmrr.com/category/ai), [Entertainment](https://trustmrr.com/category/entertainment)
