## Startup Insights

- Value proposition: Clowd is a permanent link hosting platform — upload a file or website once, get a URL that never changes, and update the content anytime.
- Problem solved: Eliminates the need to resend updated links or files by providing a permanent link that always serves the latest version.
- Pricing model: Free: $0/mo, Pro: $5/mo, Pro Max: $10/mo
