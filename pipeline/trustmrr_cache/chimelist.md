## Startup Insights

- Value proposition: Unlike Amazon or Zola, ChimeList lets you add gifts from any website — Etsy, IKEA, local boutiques, anywhere. One link, one list, every store.
- Problem solved: ChimeList solves the problem of having multiple gift registries by allowing users to add gifts from any website onto one list, eliminating the need for separate registries per store.
- Pricing model: Chime Card: $0/event, Chime Circle: $4.99/event, Chime Grand: $14.99/event
- Target persona: Couples and families planning events like weddings, birthdays, and baby showers
