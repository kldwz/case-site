## Startup Insights

- Value proposition: The durable runtime for production AI agents: checkpointed execution, human-in-the-loop approval, and per-step cost tracking in one platform.
- Problem solved: AI agents crash mid-run, act without oversight, and rack up untracked LLM costs. Ballast makes runs durable, adds approval gates, and attributes cost to every step.
- Pricing model: Free: $0 · Starter: $49/mo · Pro: $299/mo · Enterprise: custom
- Target persona: Engineering teams shipping AI agents to production, and their operators.
- Audience type: [B2B](https://trustmrr.com/search?targetAudience=B2B)
- Estimated user count: 0
- Additional info: Python & TypeScript SDKs, a visual workflow builder, checkpointed execution that survives crashes, human-in-the-loop approval gates, per-step cost attribution, evals, and an audit log. Self-hosting available on Enterprise.
- Markets: [Dev Tools](https://trustmrr.com/category/developer-tools)
