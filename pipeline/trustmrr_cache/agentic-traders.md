## Startup Insights

- Value proposition: AI trading agents that watch the market for you and act on your rules — no chart-watching, no code
- Problem solved: Retail traders can't watch charts 24/7. Agents arm a condition on any indicator and wake only when it fires
- Pricing model: Free, $19/month (Pro), $39/month (Elite) + token add-ons from $5
- Target persona: Retail and algo traders, MT5 users, TradingView alert users, prop-firm traders
- Audience type: [B2C](https://trustmrr.com/search?targetAudience=B2C)
- Team size: 1 person
- Funding: Bootstrapped
- Estimated user count: 250
- Additional info: Paper trading by default, MT5 Expert Advisor and TradingView webhooks for live. 8 LLM models via OpenRouter. Supabase auth with row-level security. Never holds client funds. Next.js on Vercel
- Markets: [AI](https://trustmrr.com/category/ai), [Fintech](https://trustmrr.com/category/fintech), [No-Code](https://trustmrr.com/category/no-code), [SaaS](https://trustmrr.com/category/saas)
