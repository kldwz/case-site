# 从 Copilot 到 Loop 的创业框架

> **类型**: concept (产品想法)
> **来源**: [[entities/gregisenberg]] — https://x.com/gregisenberg/status/2085405277042380834
> **采集日**: 2026-08-08

## 摘要

gregisenberg 给出了一个简单的创业方向思维框架：2024 build copilot / 2025 build Cursor / 2026 build agent / 2027 build /loop。

## 详情

### 框架
- **2024**: build a copilot for xyz（副驾驶，辅助人）
- **2025**: build Cursor for xyz（IDE 式，人机协作）
- **2026**: build an agent for xyz（自主执行，人监督）
- **2027**: build /loop for xyz（自循环，人只在关键点介入）

### 关键信息
- 他做了一个 43 分钟 masterclass，给 2 个真实例子 + 全部工具
- 另一期讲 "Graph engineering"（图谱工程）怎么让 claude code / codex 更好用

## 我的判断

适合一人公司的方向：给垂直行业（本地商家、知识付费、独立开发者）做"营销 Agent 代运营"——卖结果不卖工具。MVP 可先用 n8n + LLM 拼一个。
