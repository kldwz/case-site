## 详情

### 事实
- simonw 发现 Accenture 相当大一块 token 支出是**非工程师用 LLM 把 PDF 转 Markdown**
- 他呼吁"把 PDF 重新归类为 boomer 技术"，只想在手机上读篇文章

### 为什么是 PDF
法律合同/论文/发票/扫描件都是 PDF，且信息难检索。普通人每天被 PDF 卡住。付费方明确：大公司、法务、研究、财务都愿意为"PDF 变可问答"付钱。

### 机会
- PDF -> 干净 Markdown/可读网页 的轻量工具
- 面向"不想装软件、只想粘贴即读"的普通用户，订阅制
- 差异化在手机端体验、批量、保留表格公式、中文 PDF 支持

### 内容选题
"大公司在 AI 上花最多钱的事，居然是把 PDF 转成文字"——强反差，易爆。

### 质疑
他的数据来自一条推文，没给来源截图，量级需自行验证。
