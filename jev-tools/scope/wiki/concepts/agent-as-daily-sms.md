# Agent 先做成每日短信，别先做 SaaS

> **类型**: concept (AI工作流/产品想法)
> **来源**: [[entities/gregisenberg]] — https://x.com/gregisenberg/status/2086051269127364755
> **采集日**: 2026-08-09
> **评分**: 用户 8 / 商业 9 / 传播 9 = 26

## 摘要

很多 agent 创业该先做成"每日一条短信"，别先做 SaaS。消息够值钱，界面可以后补。反直觉，打破"创业=做网站"的思维。

## 详情

### 核心观点
> A lot of agent startups should probably start as a daily text message (not a SaaS product!)
> "Here are the 3 customers you should call today and why" etc
> Truth is, if the message is valuable enough, the interface can come later

### 为什么有效
- 验证想法最低成本：先有用户再写代码
- 不需要前端/后端/数据库，只需要一个定时发消息的脚本
- 如果消息没价值，做再多界面也白搭

## 我的判断

这是"先卖结果再建系统"的最佳实践。对一人公司尤其重要——你没有资源做完整 SaaS，但你能发短信。
