# 生产流水线搭建计划 v1

> 核心铁律（旺旺定）：流水线只自动化"手"，不自动化"脑"。
> 上游"亲自走一遍工具+产出真实体验"必须旺旺自己做，机器只接手之后的成稿/成片/分发。

---

## 一、总览：两段式流水线

```
【手动段 · 旺旺做，不可省】
  选题（待写队列）→ 亲自用工具走一遍 → 截图/录屏/口播
        │  产出原材料：源稿.md + 截图 + 录音
        ▼
【自动段 · 机器做】
  环节1 图文成稿（排版多平台格式）
  环节2 视频成片（自动剪辑）
  环节3 多平台分发（定时发布，旺旺审）
```

**关键认知**：自动段省的是手工活，省不了脑子活。垃圾原材料进去，全自动出来还是垃圾。

---

## 二、环节1：图文成稿（阶段一优先搭，最成熟）

源稿写一份，自动转为三平台格式：

| 平台 | 自动化方式 | 旺旺动作 |
|---|---|---|
| 公众号 | 已有 API 模式(grace, draft_only) → 生成草稿 | 后台审 + 点发布 |
| 头条号 | review_toutiao.py + Playwright 发布，纯文本铁律（禁 ##**- 等markdown符号） | 审 + 发（不审不发） |
| 飞书 | API 直写块 | 已在用 |

**源稿位置提议**：本地 md（Obsidian 或固定目录）做唯一源稿，飞书只是分发目标之一（非源头）。
**格式中枢**：源稿 → 脚本转 ①公众号富文本 ②头条纯文本 ③飞书块。三平台不手写，统一从源稿生成。

---

## 三、环节2：视频成片（阶段二，下周加）

- 输入：旺旺口播录音 + 截图/录屏
- 工具：剪映/CapCut/必剪 的 AI 成片（自动字幕+转场+出片）
- 现状：全自动剪质量参差，尤其中文口播识别与节奏，需旺旺试一轮选工具
- 约束：封面图用 baoyu-imagine 自生成，**禁止扒网图（侵权禁用）**
- 输出：短视频，旺旺审后发

---

## 四、环节3：多平台分发（贯穿）

- 公众号：API 草稿，旺旺审后发
- 头条：Playwright 脚本，旺旺审后发（注意 Argus 风控/遮罩，不能硬全自动）
- 飞书：API 直写
- 调度：待写队列驱动，批量生成草稿 + 定时发布

---

## 五、搭建顺序（不一次性全上）

**阶段一（本周，优先）**：图文三平台自动分发
- 旺旺写源稿（本地 md）
- 脚本自动 → 公众号草稿 + 头条纯文本 + 飞书
- 旺旺只审 + 点发
- 解决"每周4-7篇"最大手工负担

**阶段二（下周）**：加视频自动剪
- 旺旺录口播+截图 → 自动剪工具出片 → 旺旺审
- 先试一个工具，不贪多

**阶段三**：批量备稿中枢
- 待写队列 + 模板，批量生成多平台草稿，定时发（对应作战地图"周六半天批量备稿"）

---

## 六、现实约束（来自旺旺记忆，必须遵守）

1. 头条号必须人工审：review_toutiao.py 不审不发；Playwright 有风控（发文助手遮罩、作品声明勾选、Argus 检测），不能全自动硬发
2. 公众号配图：侵权图片禁止使用；自动出图必须用 baoyu-imagine / SiliconFlow Z-Image 自生成
3. 头条号输出格式铁律：纯文本、禁 markdown 符号；微头条一句一行、段间空行
4. 飞书推送用 origin，不用微信（微信 iLink 限流）
