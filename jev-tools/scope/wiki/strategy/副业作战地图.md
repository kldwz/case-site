# 副业作战地图 v1

> 导师立场：内容/教学是**收钱探针**，不是终点。最终目标是你真正挣到钱（训练营/订阅/定制）。本文件一切设计都奔着"验证谁愿付钱"去，不是奔着"开始做"去。

---

## 一、挣钱逻辑（先讲透，不绕）

你最终收钱的 3 条可能路径，按"离钱远近"排：

1. **教学产品**（付费社群/训练营/专栏）—— 内容做起来后最顺的变现，受众已信你
2. **AI 小工具订阅**（你做网页/脚本，别人按月付）—— 需要产品想法，目前缺
3. **接定制/咨询**（企业或个人花钱请你做/教）—— 从内容里被找上门

**关键认知（导师硬塞）**：
- 公众号/视频**前期不赚钱**，你档案也写"流量赚不到几个钱"。别假装做内容=搞钱。
- 内容真正的价值是**探针**：测"谁、为什么、愿为我付多少"。每篇发出去，要看的不是阅读，是"有没有人露出付钱意愿"。
- 产品想法**不靠空想**，靠你讲工具时发现的"国内没好用的这块"——记下来，第4周就是 MVP 候选。

---

## 二、起步载体：国内 AI 提效系列（干中学）

你定调"先走起来、干中学"，方向认了"国内工具系列"。

**起步第一篇（已定，归入《打工人AI自救》第1篇）**：
> 《打工人10分钟用AI搞定周报/PPT，老板看不出是AI写的》

为什么从这开头（导师理由，不服来辩）：
- 受众最大、痛点最痛（每个打工人每周被汇报折磨）
- 你演示成本最低、出片最快
- 最容易收获"我也想要"的留言 = 付钱意愿探针
- **不讲 HTML 酷炫版开头**：普通人不关心酷，关心"10分钟交差"。HTML 进阶放系列第3-4篇勾进阶用户。

**讲法铁律（来自你的内容偏好）**：
- 九边 pro 风格：个人观察开头 + 口语化 + 短段落 + 段间空两行 + 有态度 + 末尾#标签
- 不要纯新闻汇总，要单条深度+个人观点
- 商业模式/核心机制讲透，资料不够推理补全标（推测）
- 去 AI 味，禁术语堆砌、禁一段到底

## 三、发布机制（防断更命根子）

**节奏（你确认）**：
- 目标：**日更（7篇/周）**
- 保底：**每周≥4篇**（忙周底线，不可破）
- 断更红线：**连续≤2天不发 = 违规**，写进铁律

**生产机制（导师强制，反对每天现写）**：
- 每天现想选题+做演示+写+剪 = 上班族两周必断
- 正确做法：**每周固定半天批量备稿**（建议周六上午2-3h），一次性产出下周 4-7 篇素材/草稿
- 平时只做：润色 + 定时发 + 回留言
- 表面日更，实际每周深度工作半天 → 可持续

**待写队列机制（防断更核心）**：
- 维护一个"待写队列"（见第五节）
- 铁律：**每发1篇，必须补1篇进队列**。队列空了才允许断更
- 这样你永远知道下一篇写啥，不存在"明天写啥"的迷茫

## 五、4个选题池（永不枯竭，别再问我"下篇写啥"）

你后期写什么的源头是机制，不是我拍脑袋：

- **池1 国内大厂AI工具实测**：字节/阿里/百度/腾讯/金山每家都有AI功能，普通人不知道。你挨个上手测、讲踩坑。大厂月月发新，测不完。
- **池2 一个职业的"AI一天"**：按人谈，不按工具谈。"HR怎么用AI筛简历""销售怎么写话术""老师怎么出卷子"。越具体越有人付钱（HR主管会想"帮我搞这套"）。
- **池3 国外酷物本土化**：国外X火，国内能用Y达80%效果，我来演示。HTML酷炫汇报放这当进阶篇。
- **池4 你的翻车实录**：真实最有粘性。"我用AI做PPT交老板翻车了，因为……"比成功教程涨粉狠。你真在干，就真有坑。

2. 《HR一天：用AI筛100份简历只要半小时》（池2）

5. 《销售怎么用AI写跟进话术，不被客户拉黑》（池2）
6. 《字节/金山这个AI功能，90%人不知道》（池1）
7. 《我的副业第1周：我打算怎么靠AI挣到第一块钱》（池4，系列钩子）

> 队列规则：发1补1。上面消耗到剩2篇时，必须批量补满。

## 六、4周收钱假设（不是"阅读标准"，是"钱的标准"）

每周发内容前，心里挂一个**关于钱的假设**，发完看打脸没：

- **第1周假设**：职场人愿为"省时间做汇报"付注意力 → 看留言有没有"求模板/求带"
- **第2周假设**：有人愿为"某个职业的AI方案"付小钱 → 看有没有人问"能不能帮我搞"
- **第3周假设**：国外搬运有人追更 → 看有没有人问"后面还有吗/怎么系统学"
- **第4周复盘**：哪类反馈最接近"愿付钱" → 定为深扎方向；队列里记下的"国内没好工具"→ 列成 MVP 候选

**硬指标（你定可改）**：4周内至少出现 **1 次"有人愿为你的东西付≥9.9元"的信号**（留言/私信/咨询）。没出现 → 不是断更问题，是选题探针失效，下周换池主攻。
