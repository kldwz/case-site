## 本周值得单干的机会（按优先级）

### 机会 1：本地商家"语音接电话 agent"
- 目标用户：5pm 后漏接单的本地商家（维修/家政/诊所）
- 痛点：漏接 = 直接丢钱，请人不值
- 解决方案：语音 agent 接电话、问需求、 booking
- MVP：用现有语音 LLM + 日历 API，先给 3 家店免费跑一周
- 收费：¥300–800/月 代运营式订阅
- 开发难度：低（套 API，不碰模型）
- 内容钩子：选题"小店老板睡着了也在接单"

### 机会 2：小商家"营销 agent 代投"轻服务
- 目标用户：月营销预算<¥2000 的小店/个体
- 痛点：代运营¥1000/月还嫌坑，自己不会做
- 解决方案：把 08-09 #108 的闭环栈包成"你只管收钱"的服务
- MVP：先用手动串接 3 个客户跑 2 周看 ROI
- 收费：基础¥499/月 + 消耗抽成
- 开发难度：中（要接 FB/小红书数据，需账号授权）
- 内容钩子：选题 B"代运营太坑？AI 自己跑广告"

### 机会 3：AI 工具"存活清单"订阅
- 目标用户：想用 AI 但怕踩坑的普通职场人
- 痛点：教程里的工具常已死（08-09 #45）
- 解决方案：每周实测、只列"本周还活着且好用"的 10 个
- MVP：一份每周 newsletter + 一个简单站点
- 收费：免费引流 + ¥19/月 去广告版
- 开发难度：低
- 内容钩子："别再试死工具了，这 10 个这周还能用"

### 机会 4：PDF→可读 单功能工具
- 目标用户：烦 PDF 的任何人（08-09 #124/#125，Accenture 大头支出佐证）
- 痛点：手机上读不了、搜不到
- 解决方案：粘贴/上传 PDF → 干净 Markdown/网页
- MVP：一个网页表单 + LLM 转换
- 收费：按次¥0.5 或 ¥9/月
- 开发难度：低
- 内容钩子："把 PDF 重新归类为 boomer 技术"

### 机会 5：垂直软件 AI-native 重做（Yoast 类）
- 目标用户：站点主/小商家（08-09 #108 点名 Yoast ~$15M ARR）
- 痛点：老工具只给红绿点让你自己改
- 解决方案：AI 版直接帮你改，不只在旁看
- MVP：选一个插件（如 SEO/表单）做 AI-first 版
- 收费：¥39–99/月
- 开发难度：中（需领域知识）
- 内容钩子："它只告诉你错了，却不帮你改——AI 版直接改"
