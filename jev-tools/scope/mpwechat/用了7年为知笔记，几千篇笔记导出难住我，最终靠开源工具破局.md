# 用了7年为知笔记，几千篇笔记导出难住我，最终靠开源工具破局
作为为知笔记的重度用户，我连续付费了7年。从刚工作时记会议纪要、存学习资料，到后来积累的几千篇行业笔记、灵感碎片，它曾是我离不开的生产力工具。但最近两年，看着同类笔记软件陆续上线AI总结、智能分析功能，为知笔记却几乎没什么大更新，界面和核心功能还是老样子，越用越觉得跟不上需求。

下定决心换平台，却被一个问题卡住：为知笔记居然只支持单篇导出。几千篇笔记要一篇篇点导出，想想都头皮发麻，这无疑是灾难。

AI时代，我最大的变化就是：遇到困难不再慌，先问AI，再找工具、找开源项目、找平替方案，实在不行，就用AI定制一个。抱着这个心态，我开始全网搜解决方案，还好，在GitHub上找到了一个叫Wiznotes_tools的开源项目，看来这位开发者老哥，跟我有过一样的困扰。

## 一、先说说为啥非换不可
不是我喜新厌旧，实在是需求跟不上了。现在做内容、查资料，很需要AI帮着提炼重点、总结核心观点，很多新笔记软件都自带这功能，能直接对着几千字的笔记提问，秒出答案。

但为知笔记连批量导出都做不到，更别说AI相关功能了。客服反馈说暂时没有批量导出计划，让我手动慢慢导——这对于有几千篇笔记的用户来说，根本不现实。与其耗着，不如早点把自己的“知识资产”迁移出来。

## 二、开源工具Wiznotes_tools：安装步骤全实录（严格参考项目文档）
这个项目是用Python写的，操作不算复杂，所有步骤均严格对照GitHub上的项目文档，哪怕是轻度技术用户，跟着来也能搞定。

### 前提条件
先确认本地安装了Python环境（建议Python 3.7+），打开终端输入`python --version`或`python3 --version`验证版本，没装的话去Python官网下载安装，记得勾选“Add Python to PATH”。

### 具体安装步骤
1. **克隆/下载项目代码**
   打开终端，先定位到想存放项目的文件夹（比如桌面），执行命令克隆仓库；若没装Git，直接去GitHub下载ZIP包解压即可：
   ```bash
   git clone https://github.com/famotime/Wiznotes_tools.git
   cd Wiznotes_tools
   ```

2. **安装依赖包**
   项目依赖在`export_wiznotes/requirements.txt`中，执行以下命令安装，若遇权限问题可加`--user`参数：
   ```bash
   pip install -r export_wiznotes/requirements.txt
   ```
   要是网络慢，可换国内镜像源：
   ```bash
   pip install -r export_wiznotes/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

3. **配置账号信息**
   在项目**父目录**下创建`account`文件夹（注意不是子目录），再在里面新建`web_accounts.json`文件，写入账号信息：
   ```json
   {
       "wiz": {
           "username": "你的为知笔记登录邮箱",
           "password": "你的为知笔记登录密码"
       }
   }
   ```
   保存时注意文件编码为UTF-8，避免乱码。

4. **验证目录结构**
   最终目录结构需符合规范，核心文件/文件夹不能错：
   ```
   ├── account/                # 账号配置目录（与Wiznotes_tools同级）
   │   └── web_accounts.json   # 账号配置文件
   └── Wiznotes_tools/         # 项目主目录
       ├── get_wiz_notes.py    # 主程序入口
       └── export_wiznotes/
           ├── requirements.txt # 依赖清单
   ```

## 三、导出过程：
配置好后，导出流程按项目文档操作即可：
1. 先生成文件夹列表（明确要导出的范围）：
   ```bash
   cd export_wiznotes
   python get_folders_and_notes_list.py
   ```
   执行后会在`output`目录生成文件夹清单，可手动编辑控制导出范围。

2. 回到项目主目录，执行批量导出命令：
   ```bash
   cd ..
   python get_wiz_notes.py
   ```

导出过程中终端会显示进度，比如“正在导出第50篇，共1286篇”，几千篇笔记耗时半小时左右（取决于网络和图片数量）。导出完成后，`output`文件夹里会按原结构存放Markdown格式笔记，图片也会自动下载，不用手动整理。

## 四、最后想说的话
搞定导出的那一刻，真的有种“解放了”的感觉。自己积累多年的知识资产，终于能自由迁移到带AI功能的新笔记软件里，效率直接提升一个档次。

这个过程也让我更坚信：AI时代，遇到问题不用怕。不用自己从零造轮子，先找开源方案，再借助AI查问题、找教程，大部分难题都能解决。感谢那位开发Wiznotes_tools的老哥，替我们这些为知笔记老用户解了燃眉之急。

如果你也是为知笔记用户，也被批量导出困扰，不妨试试这个工具。要是怕麻烦，也可以等更简单的可视化工具，但对于想尽快迁移笔记的人来说，这个开源项目已经足够好用。

毕竟，我们的时间和知识资产，都值得更高效的工具来守护。
