# 避坑指南：我如何用10块钱，给自己的黄金交易配了个“顶级研究员”

最近黄金这行情，简直是在挑战心脏。特朗普半夜发个推，或者中东哪儿冒个火星，盘面就跟坐过山车一样。我这人比较懒，想盯着盘又不想一直刷手机，于是这两天自己动手，用 AI 搞了个自动化的“黄金大脑”。

今天不聊虚的，直接把我的**全套工具账单**和**搭建细节**拆解出来，希望能帮到想搞自动化情报的朋友。

### 一、 选型清单：这套组合最“接地气”

很多人问我：现在大模型这么多，为什么选这套？其实就三个字：**实用、省钱**。

| 角色 | 选用工具 | 成本 | 注册地址（建议收藏） |
| --- | --- | --- | --- |
| **大脑 (LLM)** | **DeepSeek-V3** | **需充值** (10元起，扫码直充) | [platform.deepseek.com](https://platform.deepseek.com/) |
| **骨架 (平台)** | **Dify** | **免费** (云端版足够用) | [dify.ai](https://dify.ai/) |

**为什么选 Dify 而非 Coze？** 字节的 Coze 确实好上手，但抓取海外网页限制多。Dify 以后能私有化部署，配合 Jina Reader 这种“暴力抓取”神器，基本没有翻不过去的墙。

### 二、 硬核实战：我是怎么一步步连线的？

在 Dify 的 Workflow 画布上，我一共布了四个阵。

#### 第一步：找个“好眼睛”（HTTP Request 节点）

我试过很多采集方式，最后发现最稳的是在 URL 前面加个 `https://r.jina.ai/`。

* **URL:** `https://r.jina.ai/https://www.jin10.com/`
* **Method:** `GET`
* **Headers:** * `Authorization`: `Bearer 你的Jina密钥`
* `X-Return-Format`: `markdown`


* **实操经验：** 记得 `Bearer` 后面有个空格。Jina 能把复杂的网页直接转成 AI 最爱读的 Markdown 格式，还能有效防止 IP 被封。

#### 第二步：手搓代码“洗数据”（Code 节点）

抓回来的网页 Body 包含了很多广告和菜单，直接喂给 AI 太浪费钱且容易产生干扰。我加了个 Python 3 节点：

```python
import re
from datetime import datetime, timedelta

def main(raw_text: str):
    # 生成北京时间，分析报告里得有时间戳才专业
    bj_time = (datetime.utcnow() + timedelta(hours=8)).strftime('%Y-%m-%d %H:%M')
    
    # 用正则切掉无用的页脚，只留快讯正文
    # 查找“重要事件”或者时间戳开头的位置
    start_match = re.search(r"### 重要事件|(\d{2}:\d{2}:\d{2})", raw_text)
    start_pos = start_match.start() if start_match else 0
    
    # 截取前4000字，省Token且保住重点
    return {
        "cleaned_content": raw_text[start_pos:start_pos+4000],
        "report_time": bj_time
    }

```

#### 第三步：调教 AI 分析师（LLM 节点）

模型选 `deepseek-chat`。最吃功夫的是 System Prompt，我给它的设定是：“你是有20年经验的黄金老兵”。

* **核心逻辑：** 强制它忽略 A 股个股公告，只看美联储预期、地缘局势和全球央行购金。
* **变量引用：** 在 User Prompt 框里输入 `{{` 引用上一步的 `cleaned_content`。

#### 第四步：临门一脚，手机弹窗（HTTP Request 节点）

最后用钉钉 Webhook。这里有个“灵异事件”：一开始一直报 `310000` 错误。

* **坑位提醒：** 钉钉的安全关键词我设了“黄金”，结果 JSON 包里如果没带这两个字就会被拒。
* **解决方案：** 把 JSON Body 改成这样：

```json
{
    "msgtype": "markdown",
    "markdown": {
        "title": "今日黄金研报",
        "text": "黄金情报分析：\n\n{{#llm.text#}}"
    }
}

```
