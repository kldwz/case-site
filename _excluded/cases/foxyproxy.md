# FoxyProxy：日活 22 万、评分 4.04：2006 年就有的代理管理工具

## 产品是什么

一个代理管理工具：可以为不同的网站设置不同的代理规则，管理多个代理配置并快速切换。2006 年上架。

## 怎么赚的钱

**免费标准版 + 付费版。** 收入从未官方披露，本站不做估算。

它的用户群很特殊：**需要频繁切换网络出口的人**（开发者、跨境从业者、隐私敏感用户）。这类人群规模不大，但需求刚、付费意愿高。

## 用户从哪来

开发者与技术人群的口碑；「proxy switcher」「代理管理」这类精准搜索词；以及二十年积累的品牌。

## 这个案例能学到什么

1. **服务"专业小众"人群也能活二十年**。人群小，但需求刚、付费意愿高。
2. **4.04 分说明它配置门槛偏高**。专业工具常有的代价。
3. **按规则自动切换是核心价值**。手动切太麻烦，规则才是产品。
4. **免费版 + 付费版适合专业工具**。让专业用户先试，重度使用再付费。
5. **2006 年进场的时间红利**。这类工具的信任需要年头。
