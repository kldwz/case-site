# PointFive：三个 8200 校友用"AI 修云账"做到 100 人 + 9600 万融资

## 产品是什么

**PointFive** 把自己定位为 **"The AI Efficiency OS"**——专门给企业找云账单和 AI 账单里的浪费，**然后让 AI 自己写修复 PR 推到代码仓库**。

它不只盯云（AWS / Azure / GCP 的虚机、K8s、数据仓库），**现在重点切 AI 推理账单**：Bedrock、Vertex、Azure OpenAI、Anthropic API、OpenAI API——一家公司一个月可能烧 240 万美金在 AI 模型调用上，**没人知道具体哪个团队、哪个项目、哪个 prompt 在烧钱**。

新一代产品 **TokenShift** 把视角拉到 IDE 层——**Coder 用 Cursor / Copilot 写代码时用的 token 也算账**，按 team 和 repo 归因。PointFive 是目前唯一一家从云账单追到 AI 编码代理 token 的厂商。

技术上号称"14 分钟出第一个修复 PR"——不是给个 Excel 报告让人去改，是 AI 自己定位浪费点、自动生成修复、推 PR 等人 review。

## 怎么赚的钱

**企业 SaaS 订阅**，按云/AI 支出规模阶梯定价——客户云+AI 支出越大，单价越高。TokenShift 作为子产品单独计费。

具体 ARR **未对外公开**，但可从侧面推算：100+ 员工（含 50+ 工程）+ 三轮融资 9600 万美金 + 客户群 Expedia / Linux Foundation / E.ON / Citizens / Fanatics / Hertz / NHCE 级别——**典型企业 DevOps/FinOps 工具 SaaS 毛利率 70%+**。

公开的官方融资时间线：
- **2024-06**：1600 万美金种子轮（Index Ventures 领投）
- **2024-11**：2000 万美金 A 轮（Salesforce Ventures 领投，老股东全跟）
- **2026-06**：6000 万美金 B 轮（Accel 领投，Index / Salesforce / Entrée / Sheva 等老股东全跟，**单笔 = 累计 1.6 倍**）

总融资 **9600 万美金**。

## 流量从哪来

1. **大客户直销**：Expedia / Linux Foundation / E.ON / Citizens / Fanatics / Hertz / NHCE 这种体量——**不是自己一个个跑出来，是投资人网络 + 创始团队行业关系**。
2. **FinOps 行业品牌定位**：把自己讲成"AI Efficiency OS"——**不是 FinOps 工具（财务视角），是工程视角的成本优化**，讲给 CTO/CFO 双边决策。
3. **创始人圈子**：Alon / Gal / Amir 三个人都是 **8200 部队**校友 + **前 IntSights 联合创始人**（IntSights 2021 年被 Rapid7 以 **3.5 亿美金**收购，到退出时已是 **3000 万美金 ARR**、数百家企业客户）——**他们的二次创业有 8200 校友圈 + VC 网络的天然信任**。
4. **行业媒体背书**：Calcalist / TechCrunch / Forbes 等报道中称其为 **"the hottest cloud startup"**——**对 B2B 客户来说这种 media signal 是采购决策加速器**。

## 站长是谁

**Alon Arvatz（CEO）、Gal Ben David（CPO）、Amir Hozez（CTO）**——三个以色列人。

- 共同背景：**以色列国防军 8200 部队**（网络安全精英单元）校友。
- **前 IntSights 联合创始人**——IntSights 是一家网络威胁情报公司，2017 年成立，2021 年被 Rapid7 以 **3.5 亿美金**收购。收购时 IntSights 已有 **3000 万美金 ARR** 和**数百家企业客户**。
- 加入 Rapid7 后被分配"压云成本"任务，**三个人在干这件事时发现：现有 FinOps 工具全是仪表盘级别，没有真正能落地的修复能力**——这是 PointFive 的起点。
- 花了**一年半**才把第一个产品打磨出来——**对企业级产品来说这个开发周期很正常**。
- 2023 年 1 月正式成立 PointFive。
- 2026 年公司 100+ 员工，大部分在以色列，少量在美国（销售+GTM）。

## 这个案例能学到什么

第一，**切"被忽略的大额支出"**。CFO 知道云账单一月 100 万美金，但没人能说清哪部分是真浪费、谁来修。**PointFive 用 AI 把这件事从"仪表盘"变成"自动开 PR"**——把"分析师 + 工程师 + PR review"三步合并成一步。**对 B2B 产品来说，"贵且没人管"是黄金切入口**。

第二，**跟着大趋势重定义问题**。云成本管理是旧战场，**但当 AI 推理成本成为新烧钱王——同样的问题在 AI 时代变成了 5 倍大**。PointFive 借势把"云 FinOps"重写成"AI Efficiency OS"——**同一帮工程团队，同样的产品底层，换一个 narrative 客户预算 +5 倍**。

第三，**创始团队的真实退出 = 最硬的信用**。三个人联手把 IntSights 做到 3000 万 ARR、3.5 亿美金退出——**再次创业时，Index / Salesforce / Accel 愿意在 18 个月内连投 3 轮 9600 万美金**。对个人创业者来说不一定能复刻 3.5 亿退出，但**"上一次项目你做到了什么"会决定你下一次能融多少钱**。

第四，**客户名 = 信任锚**。Expedia / Linux Foundation / Hertz 这种客户名放首页——**PMF 决策的第一关就过了**。对 B2B 早期项目来说，**先拿 1-2 个"行业里有名字"的客户**，比拿 100 个 SMB 更有杠杆。

第五，**不押单云单模型**。多云（AWS / Azure / GCP）+ 多模型供应商（Bedrock / Vertex / Azure OpenAI / Anthropic / OpenAI）——**对企业 CTO 来说这是采购安全的核心，对 PointFive 来说是天然的 upsell 面**。**模型无关 + 多云一体 = 不被任一上游掐脖子的产品**。
