# IDM Integration Module：日活 54 万、评分 4.55：一个"为付费软件导流"的插件

## 产品是什么

一个桥接扩展：把浏览器里的下载任务交给 IDM（Internet Download Manager，一款 Windows 上的付费下载加速软件）处理。

## 怎么赚的钱

**扩展本身免费**，它的价值是给付费软件 IDM 导流。IDM 是收费软件，扩展让它能在浏览器里被直接用起来。

收入从未官方披露，本站不做估算。

这是一个很聪明的结构：**免费扩展是付费产品的"入口插件"**。用户装了扩展 → 发现需要 IDM → 付费购买。

## 用户从哪来

IDM 老用户的主动安装；「下载加速」这类搜索词；以及"装了扩展才好用"的互补关系。

**54 万日活、4.55 分**。

## 这个案例能学到什么

1. **免费扩展可以是付费软件的获客入口**。
2. **互补品比替代品更容易卖**。扩展不替代 IDM，它让 IDM 更好用。
3. **4.55 分配 54 万日活**：说明这个组合确实有用。
4. **"必须配合某个软件"是缺点也是护城河**——用户装了就会去买。
5. **桥接类产品价值常被低估**。
