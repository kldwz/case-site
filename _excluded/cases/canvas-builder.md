# Canvas Builder：是一个 AI 驱动的无代码网站构建工具，能在几秒内生成像素级完美的生产就绪网站。

## 产品是什么

基于 CanvasAI 引擎的对话式网站生成 SaaS，用户通过聊天交互快速获得可部署的网站成品。属于设计工具/AI/无代码赛道。

## 怎么赚的钱

通过订阅制销售信用点包（如 $59/300 credits），按生成的落地页数量扣费（每页最低 $0.98）。当前 MRR $96，累计营收 $1,557。
