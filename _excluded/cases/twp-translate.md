# TWP（网页翻译）：日活 57 万、评分 4.75：一个人做的网页翻译，评分比同类高一大截

## 产品是什么

一个网页翻译扩展：支持整页翻译和划词翻译，可以切换不同的翻译引擎。

## 怎么赚的钱

**免费开源，个人开发者 Filipe Dev 作品。** 收入从未官方披露，本站不做估算。

它和上面那款「To Google Translate」形成有趣对比：同样是个人做的翻译扩展，它的评分是 **4.75**，远高于同类的 4.06。

差别在哪？大概率在**体验细节**：能否换引擎、翻译后排版是否保留、是否干扰原页面。同样解决"翻译"这件事，体验差一点，评分就差 0.7 分。

## 用户从哪来

「网页翻译」高频搜索词；开源社区的推荐；以及用户换引擎的自由度带来的口碑。

## 这个案例能学到什么

1. **同样的功能，体验决定评分差距**。4.75 vs 4.06，差的不是能力，是细节。
2. **给用户选择权**（可换翻译引擎）本身就是体验的一部分。
3. **翻译后保留排版是硬指标**。页面翻完就乱，用户立刻走。
4. **开源 + 个人开发者依然能吃下 57 万日活**。
5. **别只看日活，评分是下一轮的竞争力**。
