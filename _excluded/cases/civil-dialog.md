# Civil Dialog：不删你的评论，只是把骂人的话重写一遍

> **赛事**：Windows on Snapdragon AI Hackathon（高通 + 微软，Devpost 承办）
> **场景**：网络讨论治理：AI 实时改写攻击性发言，争议话题也能好好说话
> **奖项**：Winner · 3rd Place（第三名）
> **出处**：[作品页](https://devpost.com/software/civil-dialog) ｜ [赛事页](https://wos-ai.devpost.com/)

## 产品是什么

一个讨论工具：你写下想说的话，如果里面带有人身攻击、侮辱或过分激烈的措辞，它会**帮你改写成能继续讨论的版本**——意思保留，伤人程度降低。

它不是内容审核，不拦你发言，只是把「滚出去」变成「我不同意你的观点，理由是……」。

## 它解决了什么

网络讨论的死循环：一旦有人开骂，讨论立刻变成对骂，理性的人退出，剩下的只有情绪。

传统解法是删帖、禁言、拉黑——但这些方法都在**压制表达**，被压制的人会更愤怒，而且「谁来判定什么算骂人」本身就是争议。

## 这个解法妙在哪

1. **改「审核」为「改写」**。审核是零和的（你说 / 不许你说），改写是双赢的（你想说的还在，只是更好听）。
2. **保留表达欲**：用户最在意的不是措辞，是「我的意见被听见」。改写保住了意见，只打磨了外壳。
3. **端侧处理绕开了最大的争议**：改写在你自己的设备上完成，不上传、不留存，也就没有「平台在审查我」的问题。
4. **议题自带共鸣**：每个上网的人都被评论气过，产品不需要解释需求。

## 团队与赛事

**Windows on Snapdragon AI Hackathon**，作品页获 **Winner · 3rd Place**，409 个赞。技术栈为 .NET / Blazor / C# / C++ / Qualcomm 的 Genie SDK 与 QNN SDK，走的是端侧模型路线。

## 这个案例能学到什么

① **换一个动词，就是新产品**。从「删」到「改写」，是同一个问题的两种解法，后者的阻力小得多。

② **选一个人人经历过的痛点**。评论区吵架是互联网的公共体验，不需要市场教育。

③ **技术路线要服务于价值观争议**。端侧处理不只是性能选择，它同时回避了「平台审查」这个死结。

④ **跨平台栈是比赛利器**。.NET / MAUI 一次开发多端覆盖，适合极短的时间窗。

⑤ **项目名就是观点**。「Civil Dialog」四个字同时说明了做什么、为什么做。
