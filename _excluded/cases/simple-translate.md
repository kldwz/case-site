# Simple Translate：日活 25 万、评分 4.58：一个人做的划词翻译，开源免费

## 产品是什么

一个极简的划词翻译扩展：选中网页上的文字，弹出翻译结果。没有账号、没有设置界面、没有花哨功能——就是"选中 → 翻译"。

## 怎么赚的钱

**免费开源（MPL-2.0），作者是个人开发者 sienori。** 收入从未官方披露，本站不做估算。

它是"个人开发者做小而美工具"的典型样本：一个人、一个功能、不收费，却做到了 **25 万日活、4.58 分**。

## 用户从哪来

「划词翻译」「网页翻译」这类高频搜索词；极简体验带来的口碑；以及开源让技术人群愿意推荐。

## 这个案例能学到什么

1. **一个功能做到极致就够了**。它没有做任何"翻译之外"的事。
2. **25 万日活证明极简有市场**。用户不需要更多功能，需要更少的干扰。
3. **个人开发者 + 开源 = 零成本获客**。技术社区会主动传播。
4. **4.58 分来自"从不出错"**。极简产品最容易稳定。
5. **不收费也能做出规模**。前提是维护成本足够低。
