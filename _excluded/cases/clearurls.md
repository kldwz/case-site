# ClearURLs：日活 52 万、评分 4.26：把网址里的追踪参数自动清掉

## 产品是什么

一个链接净化工具：自动移除 URL 里的追踪参数——utm_source、utm_medium、fbclid、gclid 这些。你复制出去的链接是干净的，别人打开时也不会被追踪。

## 怎么赚的钱

**免费开源（LGPL-3.0），靠捐赠维持。** 收入从未官方披露，本站不做估算。

它的价值很隐蔽但很实在：**追踪参数藏在每一个分享出去的链接里**，大多数人根本不知道自己每次复制链接，都在帮平台做追踪。

## 用户从哪来

隐私意识提升的长期红利；技术社区推荐（这类工具最先在开发者和隐私爱好者中传开）；以及"装了就忘掉"的无感体验。

## 这个案例能学到什么

1. **解决一个用户不知道自己有的问题**。追踪参数是隐形的，这正是机会所在。
2. **4.26 分配 52 万日活**：说明它有用但偶尔误伤（有些正常参数被清掉）。
3. **无感体验是最高的产品境界**。装上之后不需要任何操作。
4. **开源让规则可审查**。哪些参数会被清掉，用户能自己看。
5. **捐赠制适合"小而刚需"的工具**。用户量够大时，小额捐赠也能维持。
