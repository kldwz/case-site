# 心岛日记：卖 3 块的情绪日记：5.6 千个评分、4.79 分

## 产品是什么

一个情绪记录与日记工具：记录当下的心情、写下想法，副标题是"难过的人不孤独"。

## 怎么赚的钱

**付费下载 ¥3.00。** 收入从未官方披露，本站不做估算。

3 元是"几乎不设门槛"的定价——对一款心理相关的工具来说，这个定价本身就是一种态度：**别让价格成为求助的障碍**。

## 用户从哪来

情绪管理与心理健康话题的传播；社交平台上关于"情绪记录"的讨论；以及低定价带来的低决策成本。

**5.6 千个评分、4.79 分**。

## 这个案例能学到什么

1. **心理类产品的定价要考虑"门槛"**。3 元意味着几乎不设障碍。
2. **4.79 分配 5.6 千评分**：说明它真的帮到了人。
3. **"难过的人不孤独"这句副标题就是全部营销**。
4. **情绪记录是长期需求**，不是一次性工具。
5. **低定价 + 高情感价值**，是这类产品最好的组合。
