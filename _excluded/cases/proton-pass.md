# Proton Pass：日活 17.7 万、评分 4.77：2023 年才出，评分却高过一众老将

## 产品是什么

一个密码管理器，由 Proton（做加密邮箱和 VPN 的那家）出品，2023 年上架。它与 Proton 生态打通，主打开源加密。

## 怎么赚的钱

**免费版 + 付费订阅**（纳入 Proton 的生态订阅体系）。收入从未官方披露，本站不做估算。

它值得注意的地方：**2023 年才出现，却拿到了 4.77 分**——高于 Bitwarden（4.58）、远高于 LastPass（3.65）和 1Password（3.80）。

原因大概率是：**Proton 在隐私领域的既有口碑直接传导到了新产品上**。

## 用户从哪来

Proton 既有用户（邮箱/VPN 用户）的直接转化；隐私圈子的口碑；以及"开源 + 加密"这个组合的说服力。

**17.7 万日活、4.77 分**。

## 这个案例能学到什么

1. **品牌口碑可以传导到新产品上**。Proton 在隐私领域的信任直接帮了它。
2. **生态打通是最强的留存机制**。密码、邮箱、VPN 一个账号全管。
3. **4.77 分说明新玩家也能快速建立信任**——前提是母公司有积累。
4. **开源 + 加密是安全产品的标配**。
5. **17.7 万日活只是开始**，生态内的转化空间还很大。
