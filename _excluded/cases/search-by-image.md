# Search by Image：日活 46 万、评分 4.61：一个人做的以图搜图，做到近 46 万日活

## 产品是什么

一个反向图片搜索工具：右键网页上的任意图片，选择用哪个搜索引擎去搜（Google、Bing、Yandex 等），找原图、找相似图、查出处。

## 怎么赚的钱

**免费开源（GPL-3.0），作者 Armin Sebastian，代码托管在 GitHub。** 收入从未官方披露，本站不做估算。

它是"把已有能力聚合到一个右键菜单"的典型：**搜索引擎本来就支持以图搜图，但每次都要手动上传很麻烦**——这个扩展把这件事压缩成一次右键。

## 用户从哪来

「以图搜图」「 reverse image search」这类搜索词；开源社区的传播；以及它解决的问题极其具体——找图源、找原作者、查证图片真伪。

## 这个案例能学到什么

1. **把"能做但很麻烦"的事变成一次点击**。这就是全部价值。
2. **46 万日活来自一个极窄需求**。说明小需求的市场比你以为的大。
3. **开源 + GitHub 托管是最轻的获客方式**。开发者群体主动传播。
4. **4.61 分来自"它只做一件事且做得好"**。
5. **聚合已有服务比自建服务聪明**。零成本、零维护。
