# Salient：从卧室 demo 到替车贷机构催收，零流失、年化 2500 万

## 产品是什么

Salient 做的是 **AI 催收与还款安排代理**，客户是汽车金融公司（lenders）。

车贷逾期了，传统做法是人工呼叫中心一轮轮打电话、谈还款方案、走合规话术。Salient 用 AI 代理接管这套流程——自动发还款提醒、跟借款人协商方案、全程合规留痕，替代昂贵且难扩的人工呼叫中心。

对 lender 来说，价值很硬：**每一通催收电话都直接关系到回款**，而人工又贵又难规模化。

## 怎么赚的钱

**B2B SaaS + 按结果计费**：

- 基础平台订阅
- 按成功处理的还款/联络量加收，机构先试再扩

经营数据（公开披露）：

- 年化：**约 2500 万美金**（约 208 万美金/月 run rate）
- 估值：**约 5 亿美金**
- 融资：YC W23，累计约 **7500 万美金**，a16z 与 Matrix 领投
- 客户留存：**官方称零客户流失**

## 流量从哪来

第一，**从一家大客户打透**。Salient 从 Westlake（美国大型汽车金融公司）切入，把它做成标杆。金融采购是强关系型，一个 Westlake 案例抵千次冷邮。

第二，**用「零流失」做信任锚**。金融客户最怕 AI 出合规事故，Salient 把「零流失」当信任状——对 CRO 来说，不掉客户比增长更打动人。

第三，**YC 网络带来首批机构客户**。W23 的身份在金融圈有背书效应。

## 站长是谁

**Ari Malik（CEO）** 与 **Mukund Tibrewala（CTO）**。

Ari 前 Tesla、Goldman Sachs、哥伦比亚大学；Mukund 前 Airtable、Dropbox。一个懂行业与资本，一个懂大规模产品工程——这套组合本身就是护城河。

公司从 Ari 卧室里的 demo 起步，YC W23 入场，做到年化 2500 万、估值 5 亿。

## 这个案例能学到什么

第一，**选「高痛苦 + 高客单 + 怕合规」的垂类**。车贷催收每通电话都值钱、监管又严，机构替代人工的意愿极强——痛点越痛，付费越爽快。

第二，**零流失比增长更打动金融客户**。CRO 怕的是出事，不是慢。把「零流失」摆出来，信任成本骤降。

第三，**一个标杆客户打透再扩张**。Westlake 这种量级客户进案例，后续获客是滚雪球。

第四，**创始人背景即护城河**。前 Tesla/Goldman + 前 Airtable/Dropbox，技术和行业组合不是随便能凑的。

第五，**按结果计费降决策门槛**。机构敢先试一小批再扩量，比「先买年单」容易签字。
