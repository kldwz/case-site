# 时间规划局：3 块钱、一个人、37.6 万个评分

## 产品是什么

一个倒计时工具：距离高考还有多少天、恋爱多少天了、距离发工资还有几天——把这些日子摆在主屏幕上，每天看一眼。

就这一件事。

## 怎么赚的钱

**一次性买断 ¥3.00。没有订阅、没有内购、没有广告。**

收入从未官方披露，App Store 也不公开销量，本站不做估算。

但 **376,071 个评分**这个数字值得琢磨：评分量通常是下载量的百分之一到千分之一，这意味着它的下载量在千万级别——而它只卖 3 块钱。

## 用户从哪来

- **学生场景刚需**：中考、高考、考研、四六级——「距离考试还有 N 天」是几千万人每年都要看的东西；
- **搜索长尾**：「倒计时」「纪念日」「天数」这些词搜索量稳定，工具一旦排上去就长期有量；
- **高分带来的榜单效应**：4.86 分让它长期挂在工具类榜单上，自然流量不断。

## 谁做的

开发者署名「霞 王」，App Store 卖家字段是个人姓名——这是一个**个人开发者**的作品。

## 这个案例能学到什么

1. **极窄的需求也能养活一个人**。它不做日程、不做待办、不做协作，只做倒计时。

2. **3 元是「不用想就买」的价格**。用户不需要比价、不需要考虑值不值，看到就买了。

3. **抓一个有周期性的刚需**。考试倒计时每年循环一次，意味着每年都有一批新用户。

4. **个人开发者的最优路径**：找一个「每天想看一眼」的小需求，做到最好，别的都不要加。

5. **工具纯粹性换高分**。不推社交、不弹窗、不轰炸推送，4.86 分就是这么来的。

> 一个人、3 块钱、一个极窄的需求——37.6 万个评分说明：小工具也能做成大生意，前提是你真的只做一件事。
