# Plane：用开源自托管挑战 Jira，靠云服务年收近千万美元

## 产品是什么
Plane 是一个对标 Linear 和 Jira 的开源项目管理工具，提供 issue 跟踪、sprint 规划、看板、甘特图和文档协作等功能。其核心卖点是极简体验与企业自托管能力，帮助团队避免被 Atlassian 等商业方案套牢。开发者可一键部署社区版，企业则选择云托管或购买支持服务。

## 怎么赚的钱
采用经典的开源变现三板斧：AGPL 协议的免费社区版吸引用户 → 付费云托管按用户席位计费 → 企业版提供专属支持与定制开发。2024 年完成 900 万美元 A 轮融资，但具体 ARR 未官方披露。

## 流量从哪来
GitHub 仓库是核心流量入口，通过开发者社区的病毒式传播建立品牌认知。清晰的竞品对标策略（"开源版 Linear"）降低了用户理解成本，详实的自托管文档则推动技术决策者采用。

## 站长是谁
印度创业者 Vamsi Krishna 于 2023 年创立，团队采用全球化远程协作模式。其成功证明新兴市场开发者也能打造被欧美企业认可的开源产品。

## 这个案例能学到什么
① 在 Linear 统治的体验赛道，用「数据主权」差异化突围 ② AGPL 让企业不敢闭源商用，自然导向付费方案 ③ 先打动极客再攻克企业，社区即销售网络 ④ 印度背景不再局限，全球协作开发成新常态
