# Lyzr：让自家 AI agent 替自己去融资，一年估值从 2.5 亿翻到 5 亿美元

## 产品是什么

**Lyzr** 是给**企业**用的 AI agent 构建平台。不是给个人玩的玩具，是给银行、保险、制造业这些「买了大模型却不知道怎么落地」的公司，提供一套能搭、能管、能审计的 agent 基础设施。

它解决的是企业最头疼的那一段：模型谁都能调，但**权限怎么控、数据怎么隔离、出了错怎么追溯、合规怎么过**，这些才是企业敢不敢把 agent 放进核心流程的关键。Lyzr 卖的就是这一层。

团队规模约 **110 人**，总部在美国新泽西州泽西城。

## 怎么赚的钱

**企业订阅 + 落地交付**。大企业买平台许可，再买实施服务把 agent 接进自己的系统。这类合同客单价高、周期长，但一旦进了核心流程就很难被换掉。

融资节奏很密集：

- 2026-03 **A 轮 1450 万美元**，Accenture Ventures 领投，估值 **2.5 亿美元**
- 2026-07 **B 轮 1 亿美元**，估值约 **5 亿美元**

**四个月估值翻倍**。这个速度在企业软件里不多见，本质上是资本市场在为「企业 agent 基础设施」这个位置定价。

## 流量从哪来

1. **创始人把融资过程本身做成了 demo**。Siva Surendira 让自家的 agent **SivaClaw** 去回答投资人的问题，前后处理了 **130 多个**问题。这不是噱头，是最硬的证明——**你敢让自己的产品去接最不能出错的场合，客户才敢把流程交给它。**
2. **开源与开发者社区**。agent 框架的采纳从开发者开始，用顺手了才会带进公司。
3. **Accenture 的渠道**。Accenture Ventures 领投意味着它的咨询顾问有动力把 Lyzr 带进客户项目里——**这是企业软件最贵也最有效的分销网络。**
4. **创始人的连续创业信用**。这不是 Siva 第一次把公司做出来，上一个公司 **PowerUpCloud** 在 2019 年被印度工业巨头 **L&T** 收购。**有过成功退出的人，融资时的说服成本低一个数量级。**

## 站长是谁

**Siva Surendira**，连续创业者，2023 年在泽西城创立 Lyzr。

他的风格很鲜明：**极度相信「自己先用」**。别的创始人做 agent 是卖给别人用，他是先让 agent 替自己去跑融资。这种「产品就是自己的生产工具」的做法，既是产品验证，也是天然的营销素材——媒体报道他的融资时，会顺带把产品讲一遍。

## 这个案例能学到什么

第一，**把自己的核心流程交给自家产品，是最强背书**。SivaClaw 回答 130 多个投资人问题，比任何白皮书都有说服力。**如果你自己都不敢用，别指望客户敢用。**

第二，**拿产业资本的钱，买的是渠道不是现金**。Accenture 投的 1450 万美元，真正值钱的是它背后成千上万的企业交付项目。**融资时问一句「这笔钱能带来什么客户」。**

第三，**企业级 AI 的门槛在治理，不在模型**。权限、审计、数据隔离这些「不性感」的功能，才是大企业愿意付钱的地方。**做 to B 别卷模型效果，卷能不能过合规。**

第四，**连续创业者的复利很大**。第一次创业积累的不只是钱，还有信任、人脉和对「什么时候该卖」的判断。**第二次创业往往比第一次快得多。**

第五，**窗口期的价值高于打磨**。四个月估值翻倍，靠的不是产品在这四个月里变好了多少，而是市场突然认同了这个位置。**踩对节奏比做得更好更重要——当然，得先有东西能踩。**
