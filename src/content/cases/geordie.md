# Geordie AI：给「会自己干活的 AI agent」套上安全绳，前 Darktrace 班底 5 个月 ARR 涨 13 倍

## 产品是什么

Geordie AI 踩在一个所有人都看得见、却很少有人做的坑上：**AI agent 越来越能自己干活，但谁来管住它？**

它的产品是 **AI agent 安全治理平台**，配一个叫 **Beam** 的运行时。简单说，当一家企业让 agent 去查数据库、发邮件、调 API 时，Geordie 在中间兜一层：规定 agent 能碰什么、不能碰什么、每一步留痕可审计、行为越界就拦下来。

2025 年初创立时，市面上的热闹全在「怎么让 agent 更聪明」，Geordie 反手做了「怎么让 agent 不闯祸」——**基建红利往往藏在趋势的反面**。

## 怎么赚的钱

面向已部署 AI agent 的大企业卖安全治理订阅。客单价高、黏性强：

- **2026-05-28 完成 3000 万美金 A 轮（Balderton 领投）**，Crosspoint 新进，General Catalyst 与 Ten Eleven 跟投，累计 **3650 万美金**，投后估值约 **1.8 亿美金**。
- **2026 年前 5 个月 ARR 增长 1300%**——这个斜率说明需求不是慢慢来，是哗一下涌上来。
- 客户是金融 / 医药这种「agent 出事就出大事」的行业：Owkin（医药 AI，靠 Geordie 多发现 327% 的问题 agent、规避 1300 万美金风险）、AlphaSense、Xapo Bank、Fitch、Synthesia、OakNorth。

## 流量从哪来

Geordie 的获客靠「安全圈三宝」：

1. **前 Darktrace 班底**：CEO Henry Comfort 是 Darktrace 美洲区 COO，联创 Hanah-Marie Darley 也出自 Darktrace，CTO Benji Weber 来自 Snyk。这支队伍的履历本身就是企业采购时最看重的「这帮人懂安全」。
2. **RSAC 2026 Innovation Sandbox 冠军**：RSAC 是安全界奥斯卡，拿了这个奖等于拿到全行业的免费信任背书，销售见客户时门槛低一大截。
3. **标杆客户案例**：Owkin「多发现 327% 问题 agent、规避 1300 万风险」这种数字，在金融 / 医药圈传开，同行自动来问。

## 站长是谁

三位创始人是一支**安全老兵天团**：

- **Henry Comfort（CEO）**：前 **Darktrace** 美洲区 COO——Darktrace 是英国网络安全独角兽，这段经历让他既懂技术又懂怎么卖给企业。
- **Hanah-Marie Darley**：同样出自 Darktrace。
- **Benji Weber（CTO）**：前 **Snyk**（开发者安全头部公司）工程师。

2025 年初在伦敦创立。伦敦 + 安全背景，证明**世界级 AI 安全公司不必挤在硅谷**——英国在网络安全领域本来就底蕴深厚。

## 这个案例能学到什么

第一，**当所有人都在「造 agent」，你去「管 agent」**。2025 年满屏都是 agent 框架、agent 工具，Geordie 没凑热闹，而是做了最容易被忽略的「安全绳」。趋势的反面常常藏着更稳的生意。

第二，**前大厂班底的信誉直接变现**。Darktrace / Snyk 的履历不是简历装饰，它让企业客户在签单前就默认「这帮人靠谱」。对 To B 安全生意，团队背景 = 第一张信任票。

第三，**拿 RSAC 这种权威奖项 = 免费顶级背书**。一个行业大奖顶得过几百万广告费，而且信任质量更高。创业者该主动去争这类「第三方盖章」。

第四，**「agent 安全」是强合规行业的刚需**。金融、医药一单出错就是千万级损失，所以 Owkin 这类客户一签就是大单。刚需 + 高客单，增长斜率自然陡。

第五，**伦敦也能长出世界级 AI 安全公司**。别被「必须在硅谷」的叙事绑架，英国网络安全底蕴 + 远程团队，已经是验证过的配方。
