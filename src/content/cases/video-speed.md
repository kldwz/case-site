# Video Speed Controller：一个开源的Chrome扩展，允许用户调整视频播放速度。

## 产品是什么

Video Speed Controller 是一款 Chrome 浏览器扩展，主要功能是让用户能够调整网页视频的播放速度。

## 流量从哪来

## 站长是谁

开发者是 Ilya Grigorik，在 GitHub 上维护该项目。

## 这个案例能学到什么

展示了如何通过解决一个具体的小痛点（视频速度控制）来创建有价值的工具，以及开源模式在浏览器扩展中的应用。
