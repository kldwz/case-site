# 白描：一个人，一款 OCR App，4.86 分和 4 万多个评分

## 产品是什么

拍照 / 截图 → 识别出文字 → 复制、翻译、导出。就这么一件事，白描做了八年。

它的对手是扫描全能王这类亿级用户的产品，但白描靠三件事活下来：**识别准、没广告、不强制登录**。用过大厂扫描 App 的人都知道那几句抱怨——想导出要开会员、到处是广告、不登录不让用——白描正好把这些全砍掉。

## 怎么赚的钱

**免费下载 + 内购**（高级功能买断、批量识别额度），并同时卖 Android / Windows / Mac 版本，各平台独立付费。

具体收入：未官方披露，App Store 不公开下载量和营收，本站不做估算。

这个案例的重点不是收入数字，而是**它证明了一件事**：在一个被巨头占据的刚需品类里，靠「更干净 + 买断制」依然能做出 4.86 分、4 万多个评分的产品——而评分本身又会持续带来新用户。

## 流量从哪来

1. **搜索长尾**：「OCR 识别」「图片转文字」「扫描」是搜索量极大的词，工具类产品天然吃这波流量；
2. **口碑传播**：效率类博主、B 站 UP 主、公众号常年自发推荐它，理由高度一致——「没广告、识别准、便宜」；
3. **评分即转化**：4.86 分 + 42,437 个评分，用户搜到同类产品时，这个数字就是决定因素。

## 站长是谁

开发者署名「新乐 陶」，个人 / 小团队运作，2017 年上架 iOS 版，之后扩展到多平台。

**为什么是他做成**：因为他把巨头不愿意放弃的三样东西全放弃了——广告、强制登录、订阅制。大厂要增长指标，所以必须做留存和订阅；个人开发者可以只做「好用 + 一次性付费」，这恰恰是大厂结构上做不到的。

## 这个案例能学到什么

① **巨头做不好 = 你的机会**。当对手的商业模式逼着它加广告、推订阅、要登录，你就有了反向操作的空间。

② **多平台分发是抗风险手段**。iOS / Android / Windows / Mac 全覆盖，任何一端的政策或流量变化都不致命。

③ **评分和评分数量是买不到的资产**。42,437 个评分、4.86 分，是八年口碑的沉淀，新玩家砸钱也补不上。

④ **国内用户更接受买断而非订阅**。工具型产品用一次性付费，转化的心理门槛比月订阅低得多。

⑤ **工具产品不需要内容营销**。抓住一个高频刚需词，做好体验，自然流量就够养活一个小团队。
