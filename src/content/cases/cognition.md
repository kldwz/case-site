# Cognition：把「会聊天的 AI」做成「会写代码的 Devin」，估值冲到 102 亿美元

## 产品是什么

Cognition 是 **AI 编程 agent Devin** 的母公司。Devin 不是聊天机器人，而是一个**能真干活的软件工程师 agent**：

- **自主写代码**：接到任务自己拆、自己写、自己测
- **修 bug**：定位问题、改代码、提 PR
- **开 PR / 跑流程**：直接进你的代码仓库干活

它把「AI 辅助编程」从「补全一行」推到「独立完成一个任务」。对工程团队来说，价值不是「聊得开心」，而是**真把活干完**。

## 怎么赚的钱

商业模式是**面向工程团队的订阅**（Devin + agent 平台）。资本与增长数据：

- **估值 102 亿美元**（2025-09，$400M 由 Founders Fund 领投），**累计融资 6 亿美元+**
- **Devin ARR 从 100 万（2024-09）冲到 7300 万（2025-06）**——九个月涨 70 倍
- **2025-07 收购 Windsurf**（AI 编程编辑器）
- 团队约 **200 人**

7300 万 ARR 撑起 102 亿估值，**市场买的是「agent 会干活」这条曲线的增速，而不只是当下的收入。**

## 流量从哪来

Cognition 的获客是**技术品牌 + 开发者口碑 + 新闻自带流量**。Devin 的发布 demo 本身就是广告——程序员看完自己就去试。每一轮融资、每一次收购（Windsurf）都上头条，持续带来精准的工程团队客户。**在开发者圈，产品力即营销。**

## 站长是谁

三个技术联创：

- **Scott Wu**：CEO
- **Steven Hao**：CTO
- **Walden Yan**：CPO

2023 年 11 月在旧金山创立。三人均有极强的竞赛/工程背景，**技术浓度本身就是这家公司的护城河**——做 agent 的团队，自己得先是顶尖工程师。

## 这个案例能学到什么

第一，**「会干活的 agent」比「会聊天的 bot」估值高一个量级**。聊天 bot 到处都是，能独立完成任务的 agent 稀缺，**稀缺性决定溢价。**

第二，**工程场景是 agent 最先跑通的垂直**。代码任务边界清晰、结果可验证，**最适合 agent 从 demo 走向生产。**

第三，**收购 Windsurf 补人才与产品，用资本抢时间**。自研慢，买更快，**会买公司的 agent 公司，自己也在用资本做整合。**

第四，**估值靠 ARR 增速**。7300 万 ARR 配 102 亿估值，市场赌的是曲线延续，**增长叙事比当期利润更能撑估值。**

第五，**三人联创（CEO/CTO/CPO）技术浓度即护城河**。做 agent 的团队，本身得是顶尖工程师，**人才密度就是产品力。**
