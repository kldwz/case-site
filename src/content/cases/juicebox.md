# Juicebox：两个 20 岁不到的年轻人，把招聘搜索变成了「说话」

## 产品是什么

Juicebox 做了一个叫 **PeopleGPT** 的东西——本质是给招聘者的 AI 搜索。

传统招聘软件里找人，你得写 Boolean 语法、在一堆筛选项里勾勾选选。Juicebox 把这件事变成一句话：你直接用自然语言描述「我要找一个在旧金山、做过支付、待过早期创业公司、会 Python 的人」，它就去它聚合的 **8 亿+ 候选人档案**里给你捞出来。

档案来自 30+ 个公开和半公开来源，统一聚合进一个库。你不用懂任何搜索语法，说话就行。

对招聘者来说，最大的卖点不是「更智能」，而是**省时间**——官方口径是帮招聘者省下大约 90% 的找人时间。

## 怎么赚的钱

**B2B SaaS 订阅**，按搜索量和席位分级收费：

- 中小招聘团队买 PeopleGPT 的搜索席位
- 大体量客户（大厂 HR、猎头公司）买 API 和定制化数据接入

营收曲线（公开披露）：

- 客户：**5000+ 招聘团队与公司**在用
- 年化：**约 3000 万美金**（约 250 万美金/月 run rate）
- 融资：2026 年 3 月完成 **8000 万美金 B 轮**，估值 **8.5 亿美金**，投资方 DST Global、Sequoia、Coatue、YC

从 0 到 5000+ 客户、年化 3000 万，两个创始人一个 22 岁、一个 19 岁。

## 流量从哪来

第一，**产品本身就是传播素材**。PeopleGPT 的 demo 太好懂了——「我说一句话，它搜出一堆人」——天然契合「AI 让招聘变简单」的叙事，在 X 和招聘社群被大量转发。

第二，**数据广度形成飞轮**。覆盖 8 亿+ 档案、30+ 来源，求职者和招聘者都往里涌，搜索结果越准、用的人越多，反过来又喂数据。

第三，**口碑而非广告**。它是企业级工具，采购决策看同行在用谁。5000+ 客户本身就是最好的获客引擎。

## 站长是谁

**David Paffenholz（22 岁）和 Ishan Gupta（19 岁）**，都是美国人。

David 之前做过招聘相关的产品，Ishan 年少成名。两人 2023 年前后在美国创立 Juicebox，属于 YC 系。

最反直觉的点在于：做企业级招聘 SaaS，通常被认为是「要行业人脉、要销售铁军」的生意。这两个年轻人证明——**只要产品把专业门槛降到「说话」这么低，年轻人也能直接撬动大市场**。

## 这个案例能学到什么

第一，**把专业岗位的痛苦做成自然语言入口**。招聘者的真实障碍不是「没有工具」，是「工具太难用」。Juicebox 砍掉 Boolean 语法，等于砍掉了一整层使用门槛。

第二，**数据广度就是护城河**。30+ 来源、8 亿+ 档案，单点工具很难追。做搜索/匹配类产品的，先想清楚数据从哪来。

第三，**用可量化收益做价值锚**。不说「更智能」，说「省 90% 时间」。企业客户为可量化收益付费，不为形容词付费。

第四，**先有真实使用数据再融资**。5000+ 客户不是融来的，是产品跑出来的。这成了 B 轮最硬的谈判筹码。

第五，**年轻人也能做企业级 SaaS**。19 和 22 岁，不是劣势，是「没被旧范式驯化」的优势。
