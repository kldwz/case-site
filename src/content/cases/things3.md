# Things 3：卖 68 块的待办工具：5 千多个评分、4.79 分

## 产品是什么

一款知名的任务管理工具：待办、项目、日程整合，设计精致，苹果生态深度整合。

## 怎么赚的钱

**付费下载 ¥68.00**（且各平台分别收费：iPhone、iPad、Mac 各买一次）。收入从未官方披露，本站不做估算。

在"待办工具几乎全免费 + 订阅"的时代，Things 3 坚持**高价买断**，而且是**分平台收费**——这在今天几乎是异类。

它服务的是那批"愿意为设计和不订阅付溢价"的用户。**5 千多个评分、4.79 分**。

## 用户从哪来

效率工具爱好者圈子（GTD 圈子非常紧密）；苹果生态用户的口碑；以及"反订阅"的情绪——越来越多的人厌倦了每月付费。

## 这个案例能学到什么

1. **反订阅情绪是一个真实的市场**。有人就是不想每月交钱。
2. **分平台收费是"最贵"的定价策略**，能接受的用户是最高价值的。
3. **4.79 分配 5 千评分**：小而精，且极度忠诚。
4. **设计本身就是定价理由**。
5. **高价买断需要产品真的配得上**。一次付费 = 终身期待。
