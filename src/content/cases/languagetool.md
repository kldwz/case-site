# LanguageTool：在 Grammarly 旁边，靠开源和自托管活下来

## 产品是什么

一个多语言语法与拼写检查工具：在网页输入框、邮件、文档里实时划线提示错误，支持英语、德语、法语、西班牙语等几十种语言。

代码开源，Firefox 上日活 **343,682**，评分 **4.382**（5,309 条评价）。

## 怎么赚的钱

**开源免费版 + Premium 订阅。** 免费版覆盖基础校对，Premium 提供更高级的语法、风格与改写建议，另有面向企业和团队的方案。

收入从未官方披露，本站不做估算。

## 用户从哪来

- **搜索需求**：「语法检查」「grammar checker」是搜索量巨大的词；
- **开源带来的社区传播**：技术人群愿意推荐能自托管、能审代码的工具；
- **多语言带来全球用户**：一套引擎支持一门新语言，就多打开一个市场；
- **企业集成**：以 API 形式接入企业内部系统。

## 谁做的

LanguageTooler GmbH，德国公司，2016 年上架 Firefox。

**为什么是他们做成**：因为这个赛道有 Grammarly 这样的巨头，正面打不赢。他们走的是**侧翼路线**——开源、可自托管、多语言——切走的正是巨头服务不到的那批人：不想把文本上传到别人服务器的人。

## 这个案例能学到什么

① **开源做分发，Premium 做收入**。免费版铺量，付费版收钱，两层不冲突。

② **一套能力，两种卖法**。个人用插件，企业接 API——同一个引擎卖两次。

③ **校对工具的口碑来自「误报少」**。4.38 分说明它的提示大多数时候是对的。

④ **多语言是最自然的扩张路径**。加一门语言，就多一个市场，边际成本很低。

⑤ **在巨头旁边活着的方法**：不是做得更好，是服务它服务不到的人。
