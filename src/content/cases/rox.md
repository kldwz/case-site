# Rox：不抢 CRM 的地盘，骑在它上面派 AI agent 干活

## 产品是什么

Rox 做的事一句话能说清：**给每个客户账户配一组 AI agent，把销售团队最累的活全部接走。**

调研客户、找联系人、写外联邮件、更新 CRM 记录、做会前简报——这些占掉销售一大半时间的杂活，agent 全部接手，人只需要拍板成交。

它接 Salesforce、Zendesk、HubSpot 这些客户已经在用的系统，在里面部署几百个 agent，每个 agent 负责一类活：监控现有客户动态、研究潜在客户、更新 CRM 记录、生成个性化外联。

**这事的颠覆性在哪？** CRM 巨头卖了几十年软件，逻辑一直是给人当记事本——销售自己录数据、自己查资料、自己写跟进。Rox 把这套逻辑翻了个面：**软件是给 agent 用的，agent 干完活把结果喂回系统，人只做判断和成交。**

## 怎么赚的钱

Rox 连收费方式都换了。不按席位收月费，按 agent 干的活收费，官方管这个计量单位叫 **Agent Actions**——干一次调研算几个 action，干多少活收多少钱。

- 免费档：每月 2000 次 action
- Core 档：50 美金/月，5000 次 action
- 企业档：定制报价

**agent 不跑就不花钱。** 对客户来说这不是买软件，是买「干完的活」，两边利益天然绑在一起。

对一个企业级产品来说，把价目表公开挂在官网、还带免费档，这在同类里相当少见。

## 流量从哪来

**第一，骑在存量系统上，零迁移成本。** 这是它最聪明的一步。客户不用换 CRM、不用搬数据、不用重新培训团队，装上就能跑。MongoDB 的 CIO 说从评估到上线只用了 45 天——对动辄以年计的企业软件实施周期来说，快得离谱。

**第二，效果数据自己会说话。** 云安全公司 Upwind 的销售每天省下 80% 的时间；通信计费公司 Rev.io 每个销售每天发 200 封个性化外联；物流公司 Pallet 用上之后所有销售指标创了历史最佳季度。这些客户自己公布的数字，比任何销售话术都管用。

**第三，自助版降低门槛。** 2026 年 8 月上线自助版，不用销售团队开会部署，注册 2 分钟开跑，小团队和个人直接付费用。

## 站长是谁

Ishan Mukherjee，前 New Relic 首席增长官。他创办的监控公司 Pixie 在 2020 年被 New Relic 收购，之后他一路做到高管。

团队里还有斯坦福 AI 教授 Chris Ré（AI 领域被引用最多的学者之一），以及 Confluent 前数据基础设施负责人。

**他的背景很关键：** 做可观测性出身，知道怎么盯住一个复杂系统、从噪音里捞出真正重要的信号。这套本事搬到销售上，就是「从一堆客户数据里看出哪个 deal 要黄」。

## 这个案例能学到什么

1. **不抢地盘，骑在地盘上面。** Rox 不逼客户换 CRM，客户零迁移成本。相比之下所有想「重新发明 CRM」的对手，都在跟客户最沉重的决策打架。
2. **计费跟效果绑死。** 按 agent 干完的活收钱，客户花钱买的是结果，不是席位。这就是为什么它能同时卖个人版和企业版——用多少付多少，谁都不亏。
3. **预映射数据关系是 B 端 AI 的生死线。** Rox 官方研究博客公布过一个数字：直接让 agent 读原始表结构，查询准确率只有 9%；预先把客户、产品、行业、联系人之间的关系定义清楚，准确率能到 99.9%。**销售数据错一个数就没人信了，谁敢用 9% 准确率的 agent？**
4. **红海里的差异化不在功能，在你站在哪一层。** 做会议智能的、做外呼的、做 CRM 的一堆，Rox 站在「存量系统之上的执行层」，谁都不得罪，谁都需要它。
5. **对手的政策收紧就是你的获客窗口。** 这个类比的另一个版本在 OpenCode 身上发生过——Anthropic 一收紧第三方调用，大批用户涌向模型无关的工具。盯住大厂的「关门」动作，那是你开窗的时机。
