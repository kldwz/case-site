# Ad Library Accelerator - Chrome Plugin for Facebook Ad Library / Meta / Instagram in Europe：一款针对欧洲市场的Meta广告库增强工具，提供实时触达数据排序和广告支出估算功能。

## 产品是什么

Chrome插件，帮助广告主分析面向欧洲受众的Meta广告活动，主要功能包括按触达数据排序广告、导出PDF报告、获取视频文字转录及广告支出估算。

## 怎么赚的钱

通过订阅制变现：专业版月费15欧元/年费10欧元每月，当前MRR为81美元。

## 流量从哪来

未披露具体流量来源，域名评分(DR)为7.0显示自然流量有限。

验证了工具类SaaS的微创新路径——在Meta官方广告库基础上增加欧洲市场专属的数据分析层，5星评分显示产品匹配度良好，但6个活跃订阅数说明商业化仍有提升空间。
