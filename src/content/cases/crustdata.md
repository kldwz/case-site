# Crustdata：三个前 Uber 工程师，把「实时公司数据」做成 AI agent 的燃料

## 产品是什么

Crustdata 做的是 **B2B 实时数据 API**——它维护着约 6000 万家公司、10 亿+ 人的实时数据库（招聘动态、融资、营收信号、技术栈变动……），卖给要这些数据的人。

谁要？三类：VC 做尽调、投行做研究、还有一大波 **AI agent 公司**——你的 agent 要帮人做商业决策，总得有「这家公司最近在招什么人」这种实时情报吧？Crustdata 就是喂给 agent 的燃料。

关键在于「实时」。很多老牌数据公司（比如 Chris 之前待的 PrivCo）是季度更新的快照，Crustdata 要的是「昨天这家公司发生了什么」，新鲜度本身就是壁垒。

## 怎么赚的钱

B2B API 订阅，按调用量或席位年费。客户把它的数据接进自己的系统或 agent，长期付钱。

增长曲线非常猛：**1.5 年内 ARR 从 50 万美金冲到 1000 万美金**——是 20 倍。2024 年 12 月拿了 **600 万美金种子轮**（YC、A Capital、GC、SV Angel、Phosphor）。

公司官网亲口说：「我们整个 GTM（go-to-market）都由自家 API 驱动。」意思就是基本不靠销售，**产品自己长出来的**。

## 流量从哪来

几乎没打广告。两条：

一是**开发者社区口碑**。API 类产品，程序员用了觉得好，会在圈子里传。二是**数据自带网络效应**——你接进来的信号越多，库越准，越准越多人用，正循环。

公司自己总结得最精炼：「We hit $10M ARR. Our entire GTM is powered by our own APIs.」——意思是产品本身既是给客户的工具，也是 Crustdata 获客的工具。**把产品用在自己销售上，零销售团队跑出 1000 万 ARR。**

## 站长是谁

**Abhilash Chowdhary**，CEO，之前在 Uber、Postmates 做机器人。Chris Pisarski 是前 PrivCo（老牌 B2B 数据公司）CEO，等于把「数据生意怎么玩」的 Know-how 带进来了。还有工程合伙人 Manmohan Grewal。

YC Fall 2024 进来，总部旧金山。

这个组合妙在互补：Abhilash 懂怎么把数据工程做大，Chris 懂数据生意的商业模式和客户，工程那边有人兜底。不是三个同质化工程师，是一整条价值链。

## 这个案例能学到什么

1. **站在 AI 浪潮的「卖铲子」位置。**  everybody 都在做 agent 应用，Crustdata 不凑热闹，做「agent 需要的数据」。应用会死一波，但铲子一直有人买。找方向时问：这股浪潮里，什么是所有人都要用的底层耗材？
2. **实时数据比静态快照值钱。** 季度更新的老库被它用「昨天发生什么」打穿。新鲜度即壁垒。做任何数据产品，先想：我的数据比别人新在哪？
3. **把产品用在自己身上是最强广告。** Crustdata 官网明说「我们整个 GTM 都由自家 API 驱动」——既真实演示能力，又省一支销售。看看你能不能把产品本身变成获取客户的工具。
4. **创始人组合要互补，别找三个自己。** 机器人工程 + 数据公司 CEO + 工程，覆盖技术、商业、交付。组队前盘点：我们缺哪块能力？
5. **窄到极致也能爆。** 1.5 年从 50 万 → 1000 万美金 ARR，做的是「实时 B2B 数据 API」一个窄口。别总想着品类多大，先在窄口里称王。
