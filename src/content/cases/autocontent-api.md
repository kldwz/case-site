# AutoContent API：是一个提供跨多种格式自动内容生成的 API 服务。

## 产品是什么

AutoContent API 是一个自动化内容生成工具，可以将内容转换为讲解视频、播客、信息图表、测验等多种格式。

## 怎么赚的钱

通过订阅模式收费，分为 Amateur ($33/mo)、Professional ($66/mo) 和 Business ($124/mo) 三个等级。当前 MRR 为 $17,036。

未披露

## 站长是谁

## 这个案例能学到什么

1. 自动化内容生成是一个有需求的市场 2. 多语言支持可以扩大潜在用户群 3. 分层定价策略可以服务不同预算的客户 4. API 形式的产品可以方便地集成到客户工作流中
