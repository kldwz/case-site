# ShipFast：8407 个 maker 在用的 Next.js 启动模板

## 产品是什么

ShipFast 是一套 **Next.js 全栈 SaaS 启动模板**——登录、支付、邮件、数据库、SEO、邮件营销、防垃圾邮件、API rate limit、Webhook 等十几个模块全部接好，git clone 下来直接用。

![ShipFast 截图：8407 makers ship faster](/cases/shipfast/site.png)

官网主页就一句话：**"Ship your startup in days, not weeks"**。下方直接显示 **"8407 makers ship faster"**——这是从 Marc Lou 官网当前截取的公开数据。

注意：模板**不是开源**。Starter $199、All-in $249、和他的课程 CodeFast 捆绑 $299。一次性买断，不订阅。

## 怎么赚的钱

ShipFast 的定价极其简单：

| 套餐 | 价格 | 用途 |
|---|---|---|
| Starter | $199 | 核心 Next.js 启动套件 |
| All-in | $249 | Starter + 进阶教程 + 1v1 答疑 |
| + CodeFast | $299 | All-in + 4 周课程（独立课原值 $349） |

创始人 Marc Lou 在自己 Newsletter 公开披露：

> **2025 年合计收入 $1,032,000**（15 条收入流），其中 **ShipFast 和 CodeFast 目前各自约 $20K/月**。

注意这是创始人**自报**——他在 X 上长期贴 Stripe 截图，是 build in public 圈子里收入透明度最高的 creator 之一，但**无第三方审计**。

副收入还有：

- 与 Vercel / Resend / Stripe / Rewardful 等的"会员专属折扣"（实际上是导流联盟）
- Wall of love / Leaderboards 曝光位
- 自己录的实战视频课程（CodeFast）

## 谁在买

ShipFast 的目标客户是**想自己做一个 SaaS 的程序员**——不是想做"大产品"的工程师，而是想做"小生意"的产品人。

它解决的具体痛点是：

> "我花 22 小时在登录注册、支付 webhook、邮件不进垃圾箱这些轮子上，结果一个 MVP 都没出来。"

这就是 ShipFast 在它的销售页反复强调的话——**不是卖代码，是卖"省下的时间"**。

## 它怎么长起来的

Marc Lou 是 build in public 的代表人物：

1. **每天公开收入**：X 上贴 Stripe 截图、Newsletter 里每月贴月报。
2. **公开做新项目**：他做完 ShipFast 后公开做 Make (AI logo)、Photo AI、Interior AI 等项目——这些项目本身就在给 ShipFast 导流（"我这个产品 24 小时做出来的，靠 ShipFast"）。
3. **课程矩阵互导**：ShipFast 模板文档里推 CodeFast 课程，CodeFast 课程里推 ShipFast 模板。两者绑成 $299 套装销售。
4. **社区与排行**：Wall of love、Leaderboards、Affiliate program 三件套，鼓励用户做出来项目后回来挂链接，链接就是社交证明。

目前 Marc Lou 的 X 粉丝 **13.5 万**，ShipFast 累计买家 **8407**（官网实时显示）。

## 这个案例能学到什么

第一，**卖"省下的时间"，不卖"实现的代码"**。开源模板到处都有，ShipFast 把"7 天就能上线"卖成结果，而不是技术。

第二，**build in public 本身就是分发渠道**。他每天公开收入、每月公开新产品，透明度成了品牌资产。

第三，**产品矩阵互导流**：模板 + 课程 + 工具站，自己做自己的联盟。$299 套装比单独卖更赚。

第四，**反面也要写**：Marc Lou 自述 2025 年上线 3 个新产品、2 个失败。2025 年总收入比 2024 年降 20%。**有受众不等于新产品一定成**。

第五，**Solo 极限运营**：Marc Lou 至今 0 员工、长期住巴厘岛。整个产品矩阵靠他一个人。这是个人开发者路线的天花板样板。
