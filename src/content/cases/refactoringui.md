# Refactoring UI：卖出的不是电子书，是"不用再求设计师"的底气

## 产品是什么

Refactoring UI 是一本写给**程序员的视觉设计电子书**，2018 年 12 月出版。

它不讲设计理论、不讲配色心理学、不讲字体的历史——它**只讲怎么让你的 Web 应用看起来不像 1995 年做出来的**。从按钮的圆角、阴影的层次、间距的节奏，到配色对比度、可读性，全都拆成可以照抄的"原则 + 例子"。

![Refactoring UI 官网：OVER 30,000 COPIES SOLD](/cases/refactoringui/site.png)

官网顶部明确写着："**OVER 30,000 COPIES SOLD**"（这是当前页面真实显示的公开数字）。

## 怎么赚的钱

**一次性买断**，无订阅。

每本约 $49-$80 之间（早鸟价 vs 正式价），**永久更新**——买一次，新版本自动发到邮箱。

创始人 Adam Wathan 在自己博客公开披露：

- **2020 全年**："it did about **$600,000 in 2020**"，并称为 **perennial seller**（常年畅销品）。
- **2022-09 Indie Hackers AMA**：累计收入超过 **$2.5M**。
- 出书时他只有 **3500 推特粉丝、1500 邮件订阅**——纯靠自有流量首周卖出 $61,392。

注意：以上数字均为创始人**本人披露**，非第三方审计。

## 站长是谁

**Adam Wathan**——也就是 **Tailwind CSS** 的作者。

他出版这本书时，还只是加拿大一个普通的 web 开发者。但这本书为他接下来两年专心做 Tailwind CSS 提供了资金和受众：

1. **第一本书**（2016 年，实战 Web 编程）：发售首周 $61,392
2. **Laravel 测试课**：累计 $100 万+
3. **Vue 进阶课**（2018）：约 $30 万
4. **Refactoring UI**（2018-12）：出版两年后年仍 $60 万，累计 $250 万+
5. **Tailwind CSS**（开源项目，2019 至今）：免费，靠着 Refactoring UI 累积的受众和现金流支撑他全职做了两年才发布

这是一个非常清晰的个人路线：**用书养自己两年 → 全职做免费开源 → 开源成功后做付费层（Tailwind UI）→ 累计 $2.5M+**。

## 这个案例能学到什么

第一，**把受众切到一句话**：不教"设计"，只教"会写代码但界面丑的程序员"怎么不丑。一个点打透。

第二，**用书和课攒本钱，再全职做免费大项目**。Tailwind CSS 之所以能在没有付费层的两年里稳定开发，是因为 Refactoring UI 一直在养 Adam。这是反 VC 思路——靠一本电子书养出世界级开源项目。

第三，**常青产品别下架**。出版两年后年还卖 $60 万，四年累计 $250 万+——好产品能自己卖 5 年以上，比订阅制更稳。

第四，**发售靠自有流量**。$61,392 首周销售来自他只有 3500 粉丝的 Twitter 和 1500 邮件订阅——证明小账号也能卖爆书，关键是你的受众是否精准。

## 反面提示

二手报道（2026 年起）指出 Tailwind Labs 因 AI 生成 UI 工具冲击付费层收入、裁员 75%。**Refactoring UI 本身仍稳定**（电子书不易被 AI 替代），但**它的兄弟产品 Tailwind UI** 正在被 AI 工具替代。这是个真实的"数字产品被 AI 冲击"案例——选这条路的后来者要预先考虑这层风险。
