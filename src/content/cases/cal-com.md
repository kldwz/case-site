# Cal.com：用开源挑战Calendly，把日程调度做成企业级基础设施

## 产品是什么  
Cal.com 是开源版"Calendly"，提供可嵌入网站的智能预约系统。开发者可自建会议调度平台，支持团队排班、多时区自动转换、与Google/Outlook日历双向同步。其核心优势在于允许企业完全私有化部署，并自定义品牌界面（白标），这在医疗、金融等注重数据合规的行业尤为关键。GitHub

## 怎么赚的钱  
采用经典的"开源核心+商业增值"模式：社区版Apache协议完全免费，通过收费云服务（个人免费，Teams档12美元/席/月）和企业定制方案变现。2021年获500万美元种子轮，2024年A轮融资2500万美元（含OpenAI Startup Fund参投），但具体ARR未官方披露。企业客户主要采购技术支持、数据合规保障和白标授权。

## 流量从哪来  
GitHub 仓库是天然展示窗口，技术文档直接面向开发者决策者。其SDK和API设计降低集成成本，大量开发者在博客/社交媒体分享接入案例，形成裂变传播。定价页面明确对比Calendly等竞品，用"无隐藏费用+源代码可见"建立信任，吸引对数据敏感的中大型客户主动咨询。

## 站长是谁  
荷兰开发者Peer Richelsen与Baïram Annan等人2021年联合创立。团队敏锐捕捉到：尽管Calendly垄断个人市场，但企业级调度存在数据主权痛点，而开源是打破SaaS锁定的最优解。

## 这个案例能学到什么  
① 在日历调度这类高频场景，开源能瓦解SaaS巨头的网络效应  
② 白标+自托管组合拳，将"数据自主权"包装成企业溢价点  
③ 开发者优先策略：SDK/API质量决定社区传播速度  
④ 用透明定价+协议合规，在敏感行业撕开巨头防线
