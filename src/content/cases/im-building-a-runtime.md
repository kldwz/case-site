# AI Agent Runtime Governance Layer：为AI代理提供运行时治理层，非提示词护栏

## 产品是什么

这是一款面向AI代理的运行时治理层产品，定位是介于AI代理与其执行环境之间的安全与控制中间层。与常见的提示词过滤方案不同，它关注的是代理在实际运行时的行为治理，包括权限管理、操作审计、策略执行和风险阻断。普通开发者可以将它嵌入自己的AI代理系统中，为代理设定可执行的边界规则，确保代理在调用工具、访问资源或执行敏感操作时符合预期。对终端用户而言，产品本身不可见，但它能降低企业采用AI代理时的安全风险，让代理更可控、可信任。
