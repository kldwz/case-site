# 沉浸式翻译：中国团队把一个"双语对照"体验，做成了一门订阅生意

## 产品是什么

翻译工具满地都是，沉浸式翻译的切入点是一个具体体验：**原文和译文同时显示**。

看英文网页时，每段下面直接跟一行中文；看 YouTube 时，字幕变成上下双行；看 PDF、ePUB、漫画也一样。它不替换原文，而是**并列**——你既看得懂，又能对照着看原文怎么写的。

就这一点点差异，让它从一堆翻译扩展里被认出来。

## 怎么赚的钱

免费 + 订阅，三层结构：

1. **免费额度**：能用，但官网明确说明「免费用户的每日翻译请求会有合理限制」，防止滥用；
2. **Pro 会员**：可接入 DeepL、OpenAI、Claude 等模型，官方称付费会员每月额度**最高 5000 万 token**——等于把「模型调用成本」打包成套餐卖；
3. **推荐返佣**：老用户推荐链接，好友 60 天内升级 Pro，推荐人拿 **20% 佣金**；另有礼品卡、兑换码体系。

收入数字从未公开，本站不做估算。

**值得学的定价设计**：允许用户自带 API Key——重度用户自己承担成本，轻度用户买套餐。既接住了白嫖用户（他们带来口碑），又不被他们的用量烧垮。

## 流量从哪来

1. **效果可视化**：双语字幕、双语网页这类效果，截图/录屏一眼就能看懂，天然适合短视频和社区传播；
2. **多场景铺搜索入口**：网页、PDF、ePUB、字幕、漫画、视频、Zotero、Google Docs——每个场景都是一批独立的搜索词；
3. **推荐返佣驱动**：老用户有真金白银的动力去安利；
4. **出海定位**：官网十余种语言，面向全球用户，避开国内翻译工具的红海。

## 站长是谁

中国团队，2022 年 11 月上架 Firefox，两年多做到 Firefox 日活 11 万。

**为什么是他们做成**：因为他们没有做「更准的翻译」，而是做了**更对的呈现方式**。翻译质量是模型的活儿（DeepL、OpenAI），他们做的是模型和用户之间的那一层体验——这层体验才是小团队的生存空间。

## 这个案例能学到什么

① **在成熟需求里改呈现方式，比拼底层能力划算**。翻译准确度拼不过大厂，但「双语并列」是产品决策，不是技术投入。

② **把成本做成套餐**。AI 产品最怕白嫖烧钱，按 token 给额度 + 允许自带 Key，两头都接住。

③ **一个核心能力 × N 个场景 = N 个入口**。PDF、字幕、漫画……每加一个场景就多一批搜索流量，研发成本却很低。

④ **返佣比广告便宜**。20% 佣金换来的用户是老用户信任背书过的，转化质量高于投放。

⑤ **中文团队出海是可行的路径**。同样的工作量，面向全球市场，付费能力和竞争环境都更友好。
