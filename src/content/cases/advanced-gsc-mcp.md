# Advanced GSC MCP


## 产品是什么

Advanced GSC MCP 是一款面向 SEO 从业者和营销团队的协议服务器工具，核心功能是让用户通过自然语言指令直接查询和分析 Google Search Console 的 SEO 数据。产品通过 OAuth 无密钥连接技术，实现与 Google 官方数据接口的安全对接，用户无需处理复杂的 API 密钥即可获取实时搜索表现数据。主要解决传统 SEO 工具需要手动导出数据、编写复杂查询语句的痛点，将关键词排名、点击率、展现量等专业指标的查询转化为对话式交互。典型使用场景包括：内容团队快速获取文章搜索表现、代理商自动生成客户周报、站长监控核心关键词波动等。其技术架构采用中间件设计，既保障了 Google 账户安全，又保留了 GSC 原始数据的准确性。


## 怎么赚的钱

采用分层订阅制：Starter 版（12美元/月）支持基础数据查询和每日更新；Pro 版（35美元/月）增加团队协作和自定义报告功能；Agency 版（100美元/月）提供白标解决方案和 API 访问权限。根据 Stripe 验证数据，当前月经常性收入为 4,081 美元，主要来自 128 个活跃订阅用户。


## 这个案例能学到什么

1. 技术集成创新：通过 OAuth 无密钥方案降低用户使用门槛，这种『零配置接入』思路可复用到需要连接第三方平台的产品设计中。2. 需求分层策略：三个订阅档位精准对应个人用户、专业团队和代理商的不同需求层次，证明即使是工具类产品，也可以通过场景化功能拆分实现价格阶梯。3. 交互革新价值：将专业数据查询转化为自然语言交互，这种『降维设计』特别适合将复杂后台数据（如广告投放、服务器监控等）转化为小白友好型产品。4. 数据源优势：直接对接 Google 官方接口既确保了数据权威性，也形成了技术壁垒，提醒开发者在选择数据源时应优先考虑原生接口而非第三方聚合数据。
