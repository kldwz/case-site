# Canopy API：为开发者提供亚马逊数据抓取API的SaaS工具

## 产品是什么

通过标准化API接口提供亚马逊商品数据、搜索记录、评论、卖家信息等实时抓取服务，免除用户自建爬虫系统的维护成本

## 怎么赚的钱

采用免费基础版+按量付费(0美元起)+高级订阅(99美元/月起)+企业定制的分层模式，当前MRR为991美元

## 流量从哪来

未披露具体获客渠道，但开源属性可能带来技术社区自然流量

## 站长是谁

美国开发者Ryan Anderson于2022年9月创立

## 这个案例能学到什么

验证了在巨头平台(亚马逊)生态中提供基础设施工具的商业潜力，通过技术栈兼容性(REST/GraphQL/MCP)覆盖更广的开发者群体
