# Norton Safe Web：日活 32 万、评分 3.93：老牌安全厂商的浏览器插件

## 产品是什么

一个安全浏览扩展：给搜索结果和网站打安全评级，拦掉已知的危险站点。由 Norton（诺顿）出品。

## 怎么赚的钱

**免费**（配合 Norton 的付费安全套件）。收入从未官方披露，本站不做估算。

它的商业逻辑是"**免费插件给付费安全软件导流**"——和前面写的 IDM Integration Module 是同一类结构，只是它面向的是安全市场。

**3.93 分**说明用户对这类"常驻评级"插件并不买账。

## 用户从哪来

Norton 既有用户的安装；「网站安全查询」这类搜索词；以及"多一层防护"的心理。

## 这个案例能学到什么

1. **"免费插件导流付费软件"是成熟打法**。
2. **3.93 分配 32 万日活**：导流有效，但体验一般。
3. **安全评级对用户来说是"看不见的价值"**。
4. **老牌厂商的品牌能带来安装量，但带不来好评**。
5. **别让插件变成付费软件的广告位**。
