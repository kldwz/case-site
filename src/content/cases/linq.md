# LINQ：从数字名片做成"蓝气泡 API"，让 AI agent 用 iMessage 程序化发消息

## 产品是什么

**LINQ** 起点是个消费级小工具——数字名片：碰一下（或扫一下）就能把联系方式发过去。但它真正值钱的东西在后面：**它把 iMessage / RCS 做成了 API**。

什么意思？AI agent、营销系统、SaaS 工具，可以**通过 LINQ 的程序化接口，用"蓝气泡"（iMessage）给真人发消息**。在美国，iMessage 的蓝气泡比短信绿气泡信任感高得多——没人想点绿气泡里的链接。LINQ 等于帮 agent 拿到了"发蓝气泡"的能力。

现在它月发 3000 万+ 条消息、134k MAU、295% 净收入留存、零流失。从一张名片，长成了一层"通讯基础设施"。

## 怎么赚的钱

**SaaS 订阅**：个人用数字名片免费/低价，团队和开发者买 API 套餐，按席位和消息量收费。

2026 年 2 月完成 2000 万美金 A 轮（TQ Ventures 领投、Mucker Capital 跟投）。营收没公开披露，但几个数字很说明问题：3000 万+ 消息/月、134k MAU、**295% NRR（老客户今年花的钱是去年的近 3 倍）**、**零流失**。

零流失 + 近 3 倍 NRR，意味着它几乎不用靠新客拉增长，老客户自己就在膨胀——这是 SaaS 里最性感的健康指标。

## 流量从哪来

1. **消费级数字名片病毒传播**：每个用 LINQ 的人，都在线下场合把"linq"亮给别人看，等于行走的广告，C 端获客成本极低。
2. **B 端 API 客户**：Poke、Ramp、GoHighLevel、Clay、Lindy、Pika 等 100+ 团队用它的接口发消息，尤其 AI agent 公司（Lindy/Pika/Clay）最爱"蓝气泡"这种高信任通道。
3. **标杆客户链式口碑**：Ramp、Clay 这类头部一用，同圈子的 AI 公司自然跟进来。

## 站长是谁

**Elliott Potter（CEO）**，前 Shipt（外卖独角兽）；**Patrick Sullivan（CTO）**、**Jared Mattsson（president）**。2019 年在阿拉巴马伯明翰创立，比"AI agent 热"早了几年——它本来是个名片工具，是后来 agent 爆发才把它的通讯能力点石成金。

创始团队的消费互联网背景（Shipt）很关键：他们懂"怎么让普通人也愿意用一个新联系方式"，LINQ 的病毒传播基因就是从这儿来的。

## 这个案例能学到什么

第一，**C 端做流量池，B 端开 API 变现**。数字名片圈住海量普通用户，再把这些用户的通讯通道做成 API 卖给公司——**消费级获客、企业级收钱，是经典的双向飞轮**。

第二，**抢"蓝气泡"这个心理锚**。iMessage 蓝气泡在美国 = 信任，绿气泡短信 = 像诈骗。LINQ 让 agent 发蓝气泡，**等于帮 AI 产品偷到了一层"像真人朋友"的亲和力**。**做通讯类产品，要盯着用户的心理偏见找机会**。

第三，**零流失 + 295% NRR 就是增长引擎**。不用拼命拉新，老客户自己膨胀。**对个人开发者：比起追新客，先把留存和增购做扎实，增长会自己发生**。

第四，**别把自己困在"工具"定位里**。LINQ 要是只说"我是数字名片"，天花板就是名片市场；它说"我是通讯基础设施"，天花板是 every agent 的 messaging 层。**定位决定天花板，差一个词差十倍**。

第五，**标杆客户带来链式口碑**。Ramp、Clay 这种头部一挂，同生态的 AI 公司跟着来。**做开发者/agent 工具，先拿下 1–2 个圈内公认的头牌，剩下的是顺水推舟**。
