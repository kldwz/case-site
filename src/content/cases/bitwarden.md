# Bitwarden：开源 + 1.65 美金一个月，做成了 101 万日活

## 产品是什么

一个开源的密码管理器：所有密码存在一个加密的库里，一个主密码解锁全部，跨设备同步，还能自己部署服务器（自托管）。

Firefox 上日活 **1,018,468**，评分 **4.5836**（9,362 条评价）。

## 怎么赚的钱

**免费版 + Premium 订阅。** 官网定价页公开标价：

| 档位 | 价格 |
|---|---|
| Premium（个人） | **$1.65 / 月**，年付 $19.80 |
| 其他档位 | 页面另见 $3.99 / $4 / $6 等 |
| 企业 / 团队 | 单独报价 |

**1.65 美金是什么概念？** 同类密码管理器普遍在每月 3-5 美金。Bitwarden 直接把价格砍到对手的三分之一——这不是定价策略，这是竞争武器。

收入从未官方披露，但定价是公开可查的，比任何「月入 X 万」的传闻都实在。

## 用户从哪来

1. **开源带来的口碑**：技术人群会主动推荐能审代码的工具，这种推荐的可信度远高于广告；
2. **「平替」搜索需求**：搜「1Password 替代品」「开源密码管理器」，它就是答案；
3. **自托管能力吸引企业与极客**：「数据在自己手里」对一部分客户是决定性的；
4. **免费版的漏斗**：先让所有人免费用，重度用户再升级。

## 谁做的

Bitwarden Inc.，2016 年上架 Firefox，代码开源。

**为什么是他们做成**：因为他们把两件事同时做到了——**价格砍到骨折** + **代码完全开源**。前者解决转化，后者解决信任。而密码管理器这个品类，信任恰恰是最大的购买障碍。

## 这个案例能学到什么

① **开源就是获客渠道**。能审代码这件事，对技术人群的说服力超过任何营销文案。

② **把价格砍到对手的三分之一**。在功能相近的成熟品类里，价格是最锋利的差异化。

③ **免费版要真的好用**。先让所有人用起来，付费转化只是时间问题。

④ **自托管是 B 端敲门砖**。愿意为「数据在自己手里」付钱的客户，客单价高得多。

⑤ **安全类产品的好评来自「从没出过事」**。4.58 分是多年稳定的结果，不是功能堆出来的。
