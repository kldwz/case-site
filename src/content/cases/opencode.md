# OpenCode：不做模型也不绑 IDE，卡在中间躺着赚钱

## 产品是什么

OpenCode 是一个跑在**终端（命令行）**里的 AI 编程 agent。

说白了：程序员在命令行里用一个工具写代码，这个工具背后可以接 Claude、GPT、Gemini、DeepSeek，甚至本地跑的开源模型——**用户自己选，想换就换。**

官方有个精准的说法：**「它是刀鞘，你来带刀。」**（It is the harness, and you bring the brain.）刀是大模型，鞘是 OpenCode 这套躯干：读写文件的手、跑命令的脚、记住上下文的记忆、管理权限的神经。

它跟别家最大的区别是**模型无关**。市面上主流的编程 agent 都是厂商的分发工具——Claude Code 只能用 Anthropic 的模型，Codex CLI 推 GPT，Gemini CLI 推 Google。它们存在的目的是把开发者导向自家模型的付费。

**OpenCode 反着来：它优化的是开发者，不是厂商。**

技术上它还有个狠活——接了 LSP（语言服务器协议）。多数 agent 是把代码粘进上下文窗口瞎猜，OpenCode 能把编译器报错、类型错误、import 问题直接喂回模型。模型改完一行代码，立刻知道自己改对了没有，不用靠脑补。

## 怎么赚的钱

**核心工具完全免费，MIT 开源。** 你用自己的 API key 接任何模型，OpenCode 不抽成、不订阅、不限模型。

钱从哪来？三层：

1. **OpenCode Zen**——官方精选的托管推理服务，挑出真正适合做编程 agent 的模型，一个账单搞定，按 token 收费，带缓存优化
2. **企业版**——SSO、审计日志、私有化部署、SOC 2、气隙部署，这些大公司必须有的东西
3. **工具与培训**——围绕生态的增值服务

**这套双层定价的精髓是：免费层让你上瘾，付费层卖的是「省心」而不是「功能」。** 大量用户从免费切到付费，不是因为免费版不能用，而是因为不想自己管 key、不想自己调配置。

## 流量从哪来

**第一，开源冷启动，零广告。** 2025 年 6 月 19 日发布，没有发布会、没有 Product Hunt  campaign，就一个 GitHub 仓库和一行 curl 命令。一年后 800 万月活、17.2 万星标、900 多名贡献者、13000 多次提交。

**第二，对手的政策收紧就是它的增长机会。** 2026 年 1 月，Anthropic 开始限制第三方工具用 Claude Pro / Max 订阅认证，Cline、RooCode 这些工具一起被卡。大批用惯了 Claude Code 的程序员没地方去，直接涌到 OpenCode——两周内涨了 1.8 万星标。

**第三，中立性带来企业客户。** Cloudflare 这类公司跨团队用不同的模型和合规要求，OpenCode 一套工具全满足，还能气隙部署。

## 站长是谁

Jay V（CEO）和 Frank Wang（CTO），加拿大滑铁卢大学同学，大一第一周认识，之后一路一起创业。

他们之前的公司叫 Anomaly，第二个项目 SST（Serverless Stack，AWS Serverless 框架）走过 Y Combinator 2021 批次，拿到 100 万美金，涨到 2.5 万星标，2025 年实现盈利。Dax Raad 早期是 SST 用户，后来加入成为联合创始人。

**Jay V 说过一句很清醒的话：**「OpenCode 不是一个 AI 产品，它是一个用 AI 的产品。这个区别很重要，因为我们不赌任何一个模型或供应商会赢。」

## 这个案例能学到了什么

1. **卡在两个巨头中间做中间层。** 模型厂商是上游供应商，开发者是下游客户，OpenCode 两边都不得罪。这跟当年 Docker 的逻辑一样——不做操作系统也不做应用，做中间的容器层，两边都依赖你。
2. **开源是最便宜的获客。** 代码全放 GitHub，全世界程序员免费用、免费帮你改、免费帮你传播。零广告费，社区帮你长用户。代价是你要持续维护三到六个月才能形成飞轮。
3. **免费层 + 省事层双层定价。** 核心功能免费（用自己 key），付费的是省心（一键托管、缓存加速、不用管 key）。让用户先上瘾，自然转付费。
4. **盯住巨头的「收紧」动作。** 每次大厂改政策、限流、涨价，就是你做一波「迁移指南」内容的时机。成本为零，就是快速写一篇教程。
5. **中立性本身是护城河。** 锁死在一家模型上的工具，天然害怕那家厂商变卦；模型无关的工具不怕。在一个模型格局远未稳定的市场里，「谁赢我都能接」是极强的保险。
