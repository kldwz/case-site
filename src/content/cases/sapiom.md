# Sapiom：把 Shop Pay 做到千亿 GMV 的老兵，要给 AI agent 装一个钱包

## 产品是什么

Sapiom 做的是 **AI agent 的金融操作系统**——一句话概括：让 AI agent 能**安全、自主地花钱**。

它要解决的问题很具体：今天的 agent 能写代码、能规划工作流、能设计系统，但**干到最后一步就卡住了**——它没法自己付钱买算力、开通 API、订阅服务。整个互联网的默认假设是「屏幕前坐着一个人」：注册、绑卡、管密钥、批预算，每一步都要人。

Sapiom 把**身份（KYA）、钱包、策略引擎、风控、计量、计费、多通道结算**全部抽象成一个集成。开发者接一次，agent 就能在**你设定的规则和额度内**自主花钱。它把这件事叫做「**money 就是通用 API key**」——只要 agent 能安全地花，它就能访问任何东西。

每笔交易都会留下可验证的上下文：哪个 agent、在什么策略下、对哪个服务、结果如何。

## 怎么赚的钱

**基础设施按量计费**，先做「成本可观测与治理」，再走向完整的金融编排。

切入点的选择很聪明：agent 烧钱失控是眼下所有部署 agent 的企业最痛的问题。Sapiom 先给客户一套中央化的实时用量与开销控制（按 agent、按工作流、按外部服务细分），**用立竿见影的 ROI 建立信任**，再往上长成完整的自主支出层。

早期客户有三类：**vibe coding 平台**（给终端用户的应用接上各种服务）、**规模化部署 agent workforce 的企业**、**把外部服务嵌进 agent 工作流的垂直 AI 公司**。

资本方面：**1575 万美金种子轮由 Accel 领投**，Gradient Ventures、Array Ventures、Okta Ventures、Menlo Ventures、**Anthropic**、**Coinbase Ventures**、Formus Capital、Operator Collective 参投，另有来自 Shopify、OpenAI、Vercel、GitHub、Circle、Mercury 的战略天使。

## 流量从哪来

第一，**创始人的履历就是最强的冷启动**。Ilan Zerbib 在 Shopify 做了近五年支付工程总监，把 **Shop Pay 做到 1000 亿美金 GMV**，还从零搭起 Shop Cash。在支付这个圈子里，这个履历不需要额外解释。

第二，**投资人组合本身就是传播事件**。Accel、Menlo、Anthropic、Coinbase Ventures、Okta Ventures 同时出现在一张 cap table 上，这条新闻自己就会跑。

第三，**叙事清晰到一句话能讲完**：「下一个万亿买家不是人」。这种级别的叙事，对招聘、融资、客户教育都极度高效。

第四，**生态方成为渠道**。与 Okta 的合作不是投资关系那么简单——在机器经济里，「这个 agent 是谁、代表谁、能花多少」首先是身份问题，Okta 已有的企业信任直接为 Sapiom 铺路。

## 站长是谁

**Ilan Zerbib**，Sapiom 创始人兼 CEO，连续创业者。

他的履历几乎是为此刻准备的：先在法国国防部做过网络安全，之后联创 **Earny**——一个自动帮用户追差价退款的消费 agent（服务数百万用户，2021 年被收购），再进 **Shopify 做支付工程总监近五年**，把 Shop Pay 从规模化到 **1000 亿美金 GMV**，并从零搭建了 Shop Cash（一个把忠诚度和广告合在一起的平台）。

他在 Shopify 学到了一句后来反复讲的话：**你不能拿为上一个时代造的基础设施去服务下一个时代**。

他的历史类比很工整：

- 线下商务 → 需要塑料卡片（Visa / Mastercard）
- 互联网商务 → 需要开发者支付 API（Stripe）
- 机器商务 → 需要一套让软件跨 API 经济花钱的机制（Sapiom）

## 这个案例能学到什么

第一，**去找那道「新玩家进不来」的门**。Agent 的能力已经够了，卡住它们的是**访问权限**。找到那道卡住整条链路的门，你就站在了必经之路上——Sapiom 的判断是：所有服务都用支付来限制访问，所以**支付就是通用钥匙**。

第二，**用历史类比降低市场的理解成本**。「线下要卡、互联网要 Stripe、机器要新支出层」——三句话让投资人、客户、记者同时听懂你在干嘛。清晰的叙事在融资和获客上都是杠杆。

第三，**先解决即时痛点，再长成平台**。Sapiom 没有一上来就喊「重塑金融基础设施」，而是先做成本可观测——企业现在就在为 agent 烧钱失控头疼。用短期 ROI 换长期入口，比空谈愿景稳得多。

第四，**把复杂度打包成一个集成**。身份、钱包、策略、风控、结算——每一样都够一家公司做。Sapiom 的价值不在单点做得多深，而在**让开发者只接一次**。在基础设施生意里，摩擦力决定 adoption。

第五，**让生态方变成你的分销渠道**。Anthropic、Coinbase、Okta 同时站台，不是因为它们会给订单，而是因为它们的客户正好是你的客户——这种结构性的渠道优势，是花钱买不来的。
