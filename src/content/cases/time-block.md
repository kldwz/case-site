# 时间块：15 块钱、一个人、十年，靠一个交互创新活下来

## 产品是什么

时间记录 App 有很多，时间块的差别在**怎么记**：它把一天切成一个个时间格子，你只要在格子上点一下、选个类别，就算记完了。不用填开始时间、结束时间，不用手动算时长。

就这一个交互上的改进，让它从同类里被认出来——**记录成本从「十几秒」降到「两秒」**。

## 怎么赚的钱

- **主版本 ¥15 一次性买断**（评分 ★4.78 / 4,601 个评分）；
- **时间块青春版免费**（评分 ★4.87 / 19,443 个评分），2018 年推出。

收入从未公开，本站不做估算。

这套「低价买断 + 免费版」的双轨设计很值得学：**免费版负责吃搜索流量和口碑，付费版负责承接愿意掏钱的人**，两条线互不干扰。

## 流量从哪来

1. **时间管理 / 自我量化圈层**：这类用户会主动搜工具、主动分享方法，传播质量高；
2. **免费版带来的量**：青春版 19,443 个评分，说明免费版吃到了大量自然流量；
3. **十年沉淀的评分**：4,601 + 19,443，两个版本合计近 2.4 万个评分，是任何新 App 短期无法企及的信任基础。

## 站长是谁

开发者署名「妮 安」，个人开发者，2016 年上架，至今十年。

**为什么是他做成**：因为他解决的是一个「所有人都知道该做、但没人坚持得下来」的事——记录时间。这类产品的成败不在功能多少，而在**记录成本够不够低**，他把这件事做到了极致。

## 这个案例能学到什么

① **交互创新就是产品**。不是第一个做时间记录，但把操作成本降到两秒，就足以成为品类的代表。

② **低价买断 + 免费版双轨**。免费版吃流量，付费版收钱，比在免费版里塞广告干净得多。

③ **时间是无法用钱买到的壁垒**。近 2.4 万个评分是十年攒的，新玩家产品再好也补不上。

④ **工具要纯粹**。不做社交、不做排行榜、不做打卡社区，重度用户反而留得住。

⑤ **天天用的产品，稳定性就是生命线**。崩一次丢一批用户，个人开发者必须把稳定放在功能之前。
