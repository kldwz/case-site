# David AI：让 AI agent 造 350 个网站，再用纸质明信片卖出去，一个月 8000 美金 MRR

## 产品是什么

Brandon Doyle 做了个有点疯的实验：把一个 AI agent 接进 iMessage，给它起名「Zack Morris」，然后让它去赚钱。

规则很简单——agent 自己找需求、自己造产品、自己去找客户，Brandon 只在 iMessage 里下指令。

第一版试水是个**定制睡前故事**服务。有意思的是他没做 App：故事直接**发邮件**。他的原话很实在——"我们不想再要一个 App 了。手机里装了 50 个，每天用的就 5 个，再装第 6 个的概率基本是零。所以我们要钻进用户已经在的地方。"这条线跑出了 300 多美金月收入。

真正跑起来的是第二条线：**给本地小店做网站**。

agent 被派去筛犹他州本地商家，条件只有一个——**网站很烂，或者压根没有**。筛出来 350 家。然后用便宜的中国模型（DeepSeek、Qwen）批量把站造好，token 成本压到几分钱一个。

网站是**免费给商家的**，成品先摆在那儿。真正的产品是后面的月费订阅：建好只是钩子，代运营和维护才是生意。

## 怎么赚的钱

两层收入：

**主体是本地商家网站月费。** 商家原先没有站或者站很差，AI 先送一个成品过去，愿意继续用的按月付费、由 David AI 维护。一个月做到 **8000 多美金 MRR**。

**副线是睡前故事邮件订阅**，300 多美金/月，验证的是「不做 App、直接进邮箱」这条分发思路。

成本侧很薄：350 个站的 token 成本可以忽略（用了便宜模型），明信片 1 美金出头一张，**一轮 350 张全寄出去也就 400 美金左右**。

也就是说：400 美金的获客投入，换回每月 8000 美金的经常性收入。

## 流量从哪来

这是整个案例最值得抄的部分——**获客动作完全在物理世界里完成**。

流程是这样：

1. agent 筛出 350 家目标商家
2. 批量生成成品网站
3. agent 设计并寄出**纸质明信片**，每张印一个二维码，扫码直达那个商家自己的新站，附 David AI 的联系方式
4. 再打电话跟进

结果：350 张明信片，**341 张妥投，20% 的收件人扫了码**。

20% 扫码率是什么概念？邮件打开率能到这个数都算神迹，而这还是「扫了码 = 真的看了自己的站」，意向强度完全不是一个量级。加上电话跟进，**暖线索成交率约 20%，而纯邮件冷启动通常不到 5%**。

Brandon 自己解释了为什么走这条笨路子：

> "AI 越发达，那根钟摆就越要往线下的东西摆回去。容易的做法是群发短信——但那不合规，你会被起诉、会被罚款。或者搞 AI 语音机器人、发冷邮件。你选了更贵更麻烦的那条路，但正是这点造成了全部差别：它在向潜在客户证明，你们是来真的。"

一句话：**花钱和费劲本身就是信号**。别人不肯花的 400 美金，替你筛掉了 99% 的竞争对手。

## 站长是谁

Brandon Doyle，AI 创业者，公司 David AI（getdavid.ai），在 X 上叫 @Brandondoyle。

他是那种把 agent 当同事用的人：不是打开网页聊两句，而是**塞进 iMessage 里随时待命**。他形容自己的 agent 是 "Zack 随时听我差遣"。

这个细节比技术本身重要——工具在哪儿，决定了你一天会用多少次。放在聊天框里的 agent，和放在另一个浏览器标签页里的 agent，产出的实验次数能差一个数量级。

他对模型选型也很务实：造几百个网站这种高批量、低创造性的活，一律用便宜模型；好钢用在刀刃上。

## 这个案例能学到什么

1. **刻意选那条更麻烦的路。** 群发邮件零成本，所以人人都在发，所以没人看。寄明信片要花钱、要印刷、要等邮递，正因如此收件人才会认真看。竞争的激烈程度，和你愿意承受的麻烦程度成反比。
2. **线上造，线下送。** AI 把生产成本打到近乎零，剩下的稀缺资源是**注意力**。物理世界的触达（纸、二维码、电话）反而是现在最便宜的注意力。
3. **先给成品，再谈钱。** 不是"我帮你做个网站多少钱"，而是"你的站已经做好了，扫这个码看看"。把销售动作从说服变成了展示。
4. **别再造 App 了。** 睡前故事如果做成 App，大概率死在下载这一步。发邮件，用户零新增成本。分发渠道的选择，常常比产品本身更能决定生死。
5. **批量活儿用便宜模型。** 造 350 个站这种事，用前沿模型是纯浪费。token 成本降两个数量级，整件事的经济模型才成立。
