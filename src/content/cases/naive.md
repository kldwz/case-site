# Naïve：两个 20 岁的退学生，要让 AI agent 自己开公司

## 产品是什么

**Naïve** 做的是一件事——**把「开公司」这套繁琐流程，压缩成一个配置文件加一个 API**。

现在用 Cursor、Claude Code 这类编码 agent，一个下午就能撸出一个能跑的应用。但要把这个应用变成一家**真正在运转的公司**，还得人工折腾几周：注册法律实体、填公司文件、开银行账户、发虚拟卡、申请电话线、接云数据库、接支付、接财务软件……

Naïve 的洞察是：**过去二十年建起来的所有商业 API 和云服务，都是默认「键盘后面坐着一个人」来设计的。** 当使用者变成长时间自主运行的 AI agent，这套架构在技术和成本上都崩了。

它的方案是：开发者给 agent 一句提示，agent 生成一个配置文件，Naïve 通过**统一 API**在背后把整套运营栈备齐：

- **真实世界身份**：KYC/KYB 合规、美国 LLC 注册与 EIN、专属邮箱、电话线、虚拟借记卡（**KYC/KYB 环节仍需真人参与**）
- **云与记忆**：关系型数据库、计算、对象存储、认证，以及跨长任务的长期记忆层
- **原生集成**：对接 Stripe、GitHub、Supabase、QuickBooks、Mercury、Rippling 等一万多个工具
- **Serverless agent 运行时**：把 Claude Code、Codex、Hermes、Vetta 等跑成轻量可序列化状态，而不是租一台台虚拟机
- **模型路由与推理优化**：300 多个模型之间动态路由，常规任务走便宜模型，长任务走批量推理
- **治理防火墙**：能力边界、预算上限、敏感操作需人工批准、全量不可篡改审计日志

## 怎么赚的钱

按使用量收费。收入大致从这几层来：身份与注册、云与算力、模型路由与推理。

- 2026-08-06 **A 轮 2850 万美元**，Nexus Venture Partners 领投，YC、Zetta Venture Partners、Liquid 2 Ventures 跟投
- 天使阵容很实操：Gokul Rajaram、Apollo 创始人 Tim Zheng、前 HubSpot COO JD Sherman、DocuSign 总裁 Robert Chatwani、Codecademy 创始人 Zachary Sims、Amazon 的 Gert Lanckriet
- **累计融资约 3200 万美元**

增长数据（CEO 对 TechCrunch 的说法）：

- **上线几个月内 3 万名以上注册开发者**
- **年化收入在六个月内增长 10 倍，达到「低两位数百万美元」**
- **全职团队仅 10 人**

## 流量从哪来

1. **产品长在 agent 的工作流里，让 agent 帮你分发**。Naïve 提供一个提示词，开发者丢给 Cursor 或 Claude Code，agent 就会调用它的 API 去开通整套栈。**当用户是通过 agent 接触你的，你的分发成本几乎为零。**

2. **叙事本身就是传播燃料**。「让 AI 自己开公司」这个说法天然有话题性，TechCrunch 给了独家。**在基础设施赛道，一个能被记住的故事比一份功能清单有用。**

3. **抓的是客户最大的成本项**。CEO 说增长最快的客户群是 **AI 自动化代理商**——那些把 agent 卖给小公司的人；而增长最快的需求是**推理与 serverless agent**。

   > 「运行一家自主公司、跑一堆 agent，最大的成本项现在是推理费，所以眼下增长最快的需求是推理和 serverless agent。」

   **你的产品如果能直接砍掉客户账单上最大的那一行，销售就不需要说服。**

4. **YC 网络**持续供血。创始人在青少年时期就带着上一家公司 ezML 走过 YC，这次 YC 在 A 轮继续跟投。

5. **意外用例带来长尾**。CEO 提到有客户在上面跑**无人出镜的 TikTok 频道**——他甚至发现自己的基础设施在支撑一个发猫狗跳舞搏击 AI 视频的账号。还有人**全自动运营一家租车公司**。

## 站长是谁

**Sean Dorje（CEO）** 和 **Dennis Zax**，两位都是 **20 岁的伯克利退学生**，而且**从 14 岁起就一起写代码**。在创办 Naïve 之前，他们十几岁时就一起做了 **ezML** 并把它卖了，期间走过 YC。

用投资方的话说，这是个「读起来像 2026 年 AI agent 创业公司讽刺画」的创始人故事——**只不过营收增长是真实的、被独立报道的，不是预测。**

Dorje 对市场规模的判断：

> 「未来十年，企业在自主系统上的支出可能达到数万亿美元。Naïve 要做的就是提升每一个 token 的效率，让自主公司在经济上可行。」

## 这个案例能学到什么

第一，**去找被 AI 压缩之后新暴露出来的瓶颈**。编码被压缩到几小时，那么「开公司」就成了新的瓶颈。**每一轮技术压缩，都会把原来不显眼的环节变成最贵的环节——那就是机会。**

第二，**把产品做成 agent 能直接调用的工具**。Naïve 不是给人点的界面，是给 agent 调的 API。**当 agent 成为入口，你的分发逻辑要重写。**

第三，**盯住客户账单上最大的那一行**。他们的客户最大开销是推理费，于是 Naïve 把模型路由、上下文压缩、serverless 运行时做成了核心卖点。**能帮客户砍掉最大成本，你就不用跟客户解释价值。**

第四，**合规层正在变成新的技术壁垒**。KYC/KYB、LLC 注册、带额度上限的虚拟卡——这些「不性感」的东西，恰恰是别人抄不走的部分。**在 AI 时代，能接进真实世界制度的能力越来越值钱。**

第五，**治理不是附加功能，是准入门槛**。硬性的预算上限、敏感操作人工审批、不可篡改审计日志——**没有这些，企业级客户根本不敢让 agent 碰钱。**
