# Paper：让设计稿直接变成代码，踩中 coding agent 时代

## 产品是什么

Paper 是"为 coding agent 时代做的设计平台"——它用**真实 HTML/CSS 渲染画布**，设计稿能直接导出成生产代码（React/Tailwind），消灭设计到开发的 handoff 断层。

更关键的是它**接 MCP**：coding agent 能通过 MCP 直接读、写、改设计节点，设计师和 AI 代理在同一个"事实源"上协作。简单说：Figma 的画布，但产出的是真代码，而且 AI 能直接动手改。

## 怎么赚的钱

设计平台订阅。公开档：免费版 + 专业版 16 美金/用户/月（年付）+ 团队版定制。

2026-07 A 轮 3400 万美金（Accel 与 ICONIQ 领投，Designer Fund、WorkOS 创始人 Michael Grinich、Lovable 创始人 Anton Osika、Anthropic 与 OpenAI 工程师天使跟投）。**ARR 自 Desktop 发布后涨了 25 倍**。客户含 Ramp、Lovable、Vercel、PostHog、Quartr、YC。

## 流量从哪来

设计 + 工程双圈口碑。"设计稿直接出 React 代码"精准戳中设计师最痛的 handoff，话题自带传播。

再加顶级 AI 从业者天使背书（Anthropic/OpenAI 工程师、Lovable/WorkOS 创始人）——**既是钱，也是首批用户和信任状**。路线图公开运营，社区感强。

## 站长是谁

**Stephen Haney**，CEO/创始人，旧金山。之前做过 Modulz，也跟 WorkOS 系有交集。

约 25 人小团队，2026 年靠"agent 时代的设计工具"叙事快速起量。没有显赫大厂光环，靠"把设计和代码打通"这个具体判断立住。

## 这个案例能学到什么

第一，**押一个具体断层，而不是做又一个 Figma**。Paper 不跟 Figma 拼功能，专攻"设计→代码"那道缝——**缝越具体，价值越锋利**。

第二，**用真实 HTML/CSS 渲染，让设计稿等于生产代码**。彻底消灭 handoff，设计师产出的东西开发直接能用，不是"仅供参考"的图。

第三，**接 MCP 踩中 agent 时代**。让 coding agent 直接读写设计，等于把设计稿变成 agent 可操作的对象——**这一步让它和"AI 编程"趋势绑死**。

第四，**顶级从业者天使不仅是钱**。Anthropic/OpenAI 工程师、Lovable/WorkOS 创始人这些天使，带来首批大客户和信任背书，比纯财务投资人值钱。

第五，**小团队靠精准痛点拿大钱**。25 人、A 轮 3400 万，说明 VC 投的是"你定义的真问题"，不是人头。
