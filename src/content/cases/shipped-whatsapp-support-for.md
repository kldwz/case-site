# Agent Builder Pro：为Agent Builder Pro增加WhatsApp支持，智能转接人工

## 产品是什么

Agent Builder Pro是一个面向开发者的AI代理构建工具，近期发布了WhatsApp集成功能。该产品允许用户构建能够自动处理客户对话的AI代理，并具备智能判断何时将对话转交给人工客服的能力。普通用户可以通过该平台快速搭建用于WhatsApp等渠道的自动化客服或销售助手，从而减少人工响应时间，提升客户服务效率。
