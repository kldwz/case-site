# 1Password：订阅制标杆：日活 38 万，但评分只有 3.80，订阅制反噬的样本

## 产品是什么

老牌密码管理器，主打个人与团队市场，跨设备同步、家庭共享、企业级权限管理。它是「订阅制做得最彻底」的密码管理器之一。

## 怎么赚的钱

**订阅制**，面向个人 / 家庭 / 团队 / 企业分层收费。收入从未官方披露，本站不做估算。

但它的评分是个刺眼的数字：**3.8014（1,838 条评价）**，远低于 Bitwarden 的 4.58。

原因不复杂：从买断制转向订阅制、客户端改版引起老用户不满、涨价——**每一次商业决策都直接扣在了评分上**。

## 用户从哪来

品牌积累与企业采购渠道；但它也说明一件事：**存量用户的口碑是有记忆的，你对老用户做的每一次调整，都会被记分。**

## 这个案例能学到什么

1. **订阅制能吃掉你的评分**。1Password 功能不差，3.80 分几乎全是商业决策的代价。
2. **从买断转订阅是最痛的一次转型**。老用户会觉得"已经买过的东西又要交钱"。
3. **3.80 vs Bitwarden 4.58**：同品类里，商业模式的口碑外溢比功能差距更致命。
4. **企业客户救得了收入，救不了商店评分**。B 端买单，C 端打分。
5. **改版前先想清楚老用户**。他们的差评权重最高。
