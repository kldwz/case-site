# SponsorBlock：让用户互相帮忙跳过广告，一个开发者靠捐赠做了 5 年

## 产品是什么

你看 YouTube 视频，博主中途插一段「本视频由 XXX 赞助」的口播。SponsorBlock 的作用就是**自动跳过这一段**。

关键在于它怎么知道该跳哪里：**靠用户众包**。任何人在看视频时可以标记「赞助段从第 1 分 20 秒到第 2 分 05 秒」，标记提交到公共数据库后，所有看同一视频的人都会自动跳过。

除了赞助段，它还能跳过片头片尾、求订阅提醒、无关的前情回顾。

## 怎么赚的钱

免费、开源、靠捐赠。官网 donate 页设了 **$1 / $5 / $15** 几档，也接受 Patreon 等渠道。

作者 Ajay 在捐赠页的原话是：**「过去 5 年我一直在做 SponsorBlock 和 DeArrow 这样的开源项目，多亏你的支持，我现在能全职做这些。」**

这句话很重要——它意味着**捐赠确实支撑起了一个人的全职工作**，但具体金额从未公开。本站不做估算。

## 流量从哪来

1. **痛点自带传播性**：被 YouTube 赞助口播烦到的人，一听这个名字就知道是干嘛的，会主动搜、主动安利；
2. **众包机制本身就是增长引擎**：数据越全 → 跳过成功率越高 → 用户越愿意留下并贡献标记；
3. **开放 API 带来的二次传播**：第三方开发者基于它的 API 做了各种变体，等于免费的分发渠道；
4. **衍生项目互相导流**：Ajay 后来做的 DeArrow（给视频换正经标题和封面）在同类人群里交叉获客。

## 站长是谁

Ajay Ramachandran，独立开发者。2019 年做出 SponsorBlock，之后又做了 DeArrow，靠捐赠全职做开源。

**为什么是他做成**：因为他把「贡献门槛」压到了最低。用户不需要懂技术，看视频时随手点两下就能贡献数据——产品增长不需要他自己生产内容，用户替他生产。

## 这个案例能学到什么

① **众包数据是最轻的飞轮**。用户贡献的成本只要一两秒，数据资产就会自己长大，而维护成本几乎为零。

② **扩展只是前端，数据才是资产**。它同时开放 API，让产品从「一个工具」变成「一层基础设施」，别人愿意在它上面盖房子。

③ **切入点小到一句话说得清**。不做「更好的 YouTube 体验」，只做「跳过赞助段」，传播成本最低。

④ **全职独立开发的前提是砍掉一切支持负担**。没有企业客户、没有付费墙、没有客服，一个人才能撑住几十万用户。

⑤ **捐赠页要写「你的钱让我能做什么」**。Ajay 写的是「让我能全职做这些项目」，一句大白话，比讲情怀有用。
