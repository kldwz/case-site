# Cursor：从 VS Code 肩膀上长出来的 AI 编程编辑器，估值 293 亿

## 产品是什么

Cursor 是一个 **AI 原生代码编辑器**——本质是基于 VS Code（开源）做的深度改造，把 AI 写代码、改代码、理解整个代码库的能力做成了核心体验。

它不只是个"补全插件"，而是把 AI 嵌进编辑、重构、多文件修改、对话式开发的每个环节。2025 年 10 月还推出了**自研的 Composer 模型**，把能力进一步纵向整合到模型层。

## 怎么赚的钱

订阅制为主，外加自研模型：

- **ARR 突破 10 亿美金**
- 2025 年 11 月估值 **293 亿美金**，完成 **23 亿 Series D**，由 **Accel + Coatue** 领投
- **5 万+ 企业团队** 在用，包括 NVIDIA、Adobe、Uber、Shopify、PayPal

这套增长曲线在开发者工具里极其罕见——从 2022 年创立到百亿估值只用三年。

## 流量从哪来

1. **开发者口碑**：程序员圈子里"好用"会瞬间传开，Cursor 几乎没投过广告，靠用户自发推荐。
2. **VS Code 用户自然迁移**：基于 VS Code 做，老用户上手零成本，从"装个插件"自然过渡到"换编辑器"。
3. **免费 / 低价个人版**：养出巨大的免费漏斗，再由团队版、企业版收钱。
4. **Product Hunt / build in public**：早期靠这类渠道打响知名度。

## 站长是谁

**Michael Truell（CEO）**、**Aman Sanger**、**Sualeh Asif**、**Arvid Lunnemark**——**四名 MIT 毕业生**，2022 年创立公司 **Anysphere**。典型的"名校技术天团 + 清晰品类"组合，融资节奏因此极快。

## 这个案例能学到什么

第一，**站在开源生态肩膀上做差异化 AI 层**。VS Code 开源，Cursor 不用从零造编辑器，只把 AI 体验做透——省下十年基建，集中火力打差异点。

第二，**开发者产品靠口碑病毒传播**。程序员是最爱分享、最挑剔的用户群，产品真过硬，获客成本接近零。

第三，**从插件长成独立 IDE，再自研模型（纵向整合）**。先寄生、后独立、再向上游吃模型层——这是一条经典又高效的进化路径。

第四，**免费版养漏斗、企业版收钱**。海量个人用户是护城河，企业付费是利润来源，两不误。

第五，**明星团队 + 清晰品类 = 融资飞轮**。MIT 背景 + "AI 编辑器"这个一听就懂的定位，让顶级机构抢着投。
