# Meuze：F1 替补车手，给连锁快餐做「公司大脑」

## 产品是什么

Meuze 做的是面向连锁餐饮（QSR）的 **AI 数据聚合层**，创始人叫它「company brain」（公司大脑）。

一家快餐连锁，数据散落在 POS、外卖平台、会员系统、供应链工具里，彼此不通。Meuze 不替换任何一套系统，而是**在它们上面盖一层**，把数据聚成统一、可查询的层——老板问一句「上周哪家店外卖毛利掉了」，AI 直接答。

对餐饮老板来说，价值是「不用再开五个后台拼数据」。

## 怎么赚的钱

**B2B 数据层订阅 + 实施费**：

- 按门店数、数据模块分级收费
- 不融资，靠合同现金流扩张

经营数据（公开披露）：

- **8 周签下约 900 万美金年化合同（ARR）**
- 接进 **2000+ 门店**
- 客户含 Oakberry、Skinny Louie 等连锁
- 明确**不融资**

一个明星车手带队，8 周拿下 900 万美金 ARR，靠的是合同不是估值。

## 流量从哪来

第一，**创始人 IP 是 0 成本获客**。Jack Doohan 是 F1 Haas 替补车手，媒体和品牌方天然关注，冷启动不用花钱买流量。

第二，**「明星做苦活」的反差建立可信度**。车手去做餐饮数据层，听起来不搭，但正因不搭，落地 2000+ 门店的事实更有冲击力——说明真能干苦活。

第三，**餐饮老板圈口碑传导**。连锁之间互相认识，一个 Oakberry 跑通，同行就来问。

## 站长是谁

**Jack Doohan（F1 Haas 替补车手）** 任 CEO，联合创始人 **William Zacka（COO）**、**George Allen（CCO）**。

Doohan 开过二十年赛车、进过顶级车队替补席，跨界做 SaaS 看似跳跃，实则用了名人身份当杠杆，再用「真落地 2000+ 门店」兑现信任。

## 这个案例能学到什么

第一，**名人身份是 0 成本获客，但要用「做苦活」的反差兑现信任**。光靠名气签不下企业单，落了地才有续费。

第二，**不做产品做「层」**。聚合既有系统数据、不替换客户 IT，落地阻力最小。做企业服务，先想清楚怎么不碰客户已有架构。

第三，**用大合同证明 PMF 再扩张**。900 万美金 ARR 是比融资新闻更硬的信号。

第四，**找「数据最散」的连锁**。快餐多系统并存最痛，痛点越散，数据层价值越高。

第五，**不融资也能快**。合同现金流 > 估值叙事，尤其在利率高、VC 谨慎的时候。
