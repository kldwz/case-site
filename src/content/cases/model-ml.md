# Model ML：一对被 YC 录取三次的兄弟，要给华尔街配一个 AI 分析师

## 产品是什么

Model ML 是**给金融服务机构用的 AI 工作台**，自动化投行、私募、资管和咨询里最耗人的那部分活：研究、尽职调查、数据分析。

打开它，界面很像 Google Drive——里面有它自己版本的 Excel、PowerPoint、Word。**信息永远不需要离开工作区**。用户用自然语言提需求，它从这家机构能访问的所有数据源里抓信息，然后按你要的形式产出：一份公司画像、一张可比公司分析表、一份一百页的备忘录。

几个关键设计：

- **全面连接** — 邮件、文件、CRM、任何你有权限的数据库，还有 Capital IQ、FactSet、Crunchbase、SharePoint
- **每个数据点可回溯** — 生成可比分析时，每格信息都链回原始来源，并在原文里高亮，方便交叉核对
- **模板化** — 分析师天天做 comps，你只需要设一次，之后就是重复执行
- **部署方式** — 整个环境托管在客户自己的基础设施上，满足安全与合规要求
- **交付形态** — Excel、PowerPoint、Outlook 插件，加独立桌面应用与 API
- **合规** — SOC 2 与 ISO 27001:2022

他们的定位不是聊天机器人，而是「**跑在 agentic 系统之上的表格视图**」。常用场景包括财报摘要、趋势分析、市场图谱、从海量文档库里提取结构化信息。

## 怎么赚的钱

面向机构的订阅。客户覆盖投行、私募股权与信贷、资产管理、咨询。

这个生意的结构很有意思：**客单价高、留存强、但销售周期长**。所以对 Model ML 来说，最关键的不是功能多少，而是**能不能进得了那扇门**——这一点他们用顾问团解决了。

融资节奏是典型的三段跳：

- **2024-02** YC 种子 50 万美金
- **2025-02** 1250 万美金种子轮（YC 与 LocalGlobe 领投），同期由 Fortune 独家报道出 stealth
- **2025-11** 7500 万美金 A 轮（FT Partners 领投）

累计约 8750 万美金，部分公开渠道称总额超过一亿。

## 流量从哪来

第一，**连续创业者的信誉**。Chaz 此前创立 **Fat Llama**（YC S17，被 Hygglo 收购），Arnie 创立 **Fancy**（YC S20，被 Gopuff 收购）。两人都至少两次进 YC，有渠道称他们是唯一被 YC 录取三次的创始团队。在早期投资圈，这是极强的信号。

第二，**超规格的顾问团**。名单包括 **Sir Noel Quinn（汇丰前 CEO）**、**Axel Weber（瑞银前行长）**、**Mark Machin（CPP Investments 前 CEO）**、**Philipp Rickenbacher（宝盛前 CEO）**、**Jeff McDermott（瑞银 / 野村）**。这不是站台，这是**一张直接通向目标客户 C 级决策层的关系图**——在卖给受监管机构这件事上，它同时提供了产品可信度和分销通道。

第三，**客户名单本身**。UBS、HSBC、两家四大会计师事务所、Three Hills Capital、Equirus——在金融服务的采购决策里，同行名单的分量高于任何功能对比。

第四，**大厂生态的背书**。OpenAI 把他们做成过官方案例研究，微软的 Office 插件体系也是天然的分发位。

## 站长是谁

**Chaz Englander**（CEO）与 **Arnie Englander**（CTO），亲兄弟，2023 年在伦敦创立 Model ML。

两人都是连续创业者：Chaz 做过 **Fat Llama**（一个租赁 marketplace，YC S17，被 Hygglo 收购），负责商业与销售；Arnie 做过 **Fancy**（最后一公里配送公司，YC S20，被 Gopuff 收购），负责技术与产品。

起点很朴素——**他们最初是给自己做投资用的工具**。搭出来之后身边人开始问能不能用，2023 年才正式公司化。

Chaz 对产品的描述很精准：「基本上，你再也不用自己去搜集信息了。」以及那句被反复引用的定位：Model ML 是「跑在 agentic 系统之上的表格视图」。

他对客户心态的观察也很清醒：这些机构不是在挑下一个数据供应商或 CRM，「这东西会在他们整体业务的成败里扮演根本性的角色，所以他们——而且理应如此——会非常谨慎地斟酌自己要自动化什么、不自动化什么」。

## 这个案例能学到什么

第一，**先做给自己用**。Model ML 不是从市场分析里诞生的，是从创始人自己的投资需求里长出来的。被身边人追问「能不能给我也来一个」，是最低成本的需求验证。

第二，**在受监管行业里，数据主权是产品功能，不是技术细节**。把环境托管在客户自己的基础设施上，这不是妥协，是让合规部门点头的唯一方式。

第三，**让顾问团变成渠道**。请来前全球金融机构的 CEO，价值不在名气，在他们能直接带你进目标客户的决策层。这是嵌入式的分销通道。

第四，**专业用户要的是可验证，不是快**。Model ML 生成的每个数据点都能点回原文并高亮出处——在投行这种错了要出大事的场景里，可回溯比生成速度重要得多。

第五，**把重复劳动模板化才是真护城河**。分析师天天做 comps，设一次就能反复跑。产品一旦成为习惯性的工作流底座，替换成本就极高。

第六，**别怕伺候最难伺候的客户**。受监管、挑剔、决策链长的机构一旦进去，就很难被换掉。反过来，容易进的市场也容易被别人进。
