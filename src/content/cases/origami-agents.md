# Origami：YC F24 增长最快的 AI 探客 agent，研究 15+ 实时数据源自动帮你找客户

## 产品是什么

**Origami**（origami-agents）是给销售/增长团队做的 **AI 探客 agent**。传统探客要么买静态数据库（过期）、要么人肉刷 LinkedIn（慢）。

它换个做法：你告诉它"我要找这类客户"，它自动研究 **15+ 个实时数据源**（新闻、招聘、融资、社媒、招标……），判断"此刻谁最可能在买"，还顺手把 outreach 文案写好。等于雇了个不睡觉的 BD，而且比人看得全。

它是 YC F24 批次里**增长最快的公司之一**，beta 期就跑出约 5 万美金 MRR。

## 怎么赚的钱

**按席位订阅**，卖给有获客需求的销售/增长团队。它替掉的不是某个工具，是"销售研究员"这份人力，客单价按席位走。

融资：2025-01 **种子轮 200 万美金（YC + Antigravity + Pioneer）**。还在 beta 就做到 5 万美金 MRR，说明 PMF 已经验证——小 MRR 也能证明大市场存在。

## 流量从哪来

1. **YC 品牌**：F24 批次，YC 背书自带流量和信任。
2. **销售圈口碑**：销售负责人最懂探客痛，用爽了会安利。
3. **客户案例展示**：CBRE、Clipboard Health、Remote.com 这些知名客户往官网一挂，就是信任状。
4. **产品演示传播**："AI 自动研究 15 个数据源找客户"的 demo 反直觉、好传播。

## 站长是谁

**Finn Mallery（Stanford 退学）** 和 **Kenson Chung（UCL 退学）**，2024 年在旧金山创立，都二十出头。

两个名校退学生，赌的是"探客是销售里最适合被 agent 化的环节"——高频、重复、依赖多源信息、判断标准清晰。他们把这件事做成 agent，正好踩中 2024-2025 的 AI agent 热潮。**年轻人 + 清晰场景，跑出了 YC F24 最快增长。**

## 这个案例能学到什么

第一，**探客是销售最痛的环节，最适合 agent 化**。高频、重复、要扫多源信息、判断标准清——完美是 AI agent 的活。**挑"人干得烦、AI 干得准"的环节下手。**

第二，**用"实时数据源"做差异化**。静态数据库会过期，Origami 卖的是"此刻谁在买"。**不卖库存卖实时，护城河更活。**

第三，**名校退学猛干在 AI agent 圈跑通了**。Finn/Kenson 赌对方向，YC F24 增长最快就是回报。**看准场景，年轻人也能跟大厂抢。**

第四，**知名客户案例是最强信任状**。CBRE 往官网一挂，Enterprise 客户立马放心。**B2B 晒大客户比啥广告都管用。**

第五，**小 MRR 也能验证大市场**。beta 5 万美金 MRR 就说明 PMF，不用等做到百万才确认方向。**早期用真实收入验证，比融资额更准。**
