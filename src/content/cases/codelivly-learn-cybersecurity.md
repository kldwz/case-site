# Codelivly - Learn Cybersecurity


## 产品是什么

Codelivly是一个专注于网络安全实战技能培养的在线学习平台，主要面向希望系统学习网络安全技术的入门者和进阶者。平台通过电子书、在线课程和实战训练项目三位一体的教学体系，帮助用户从零基础逐步掌握渗透测试、漏洞挖掘等实用技能。其核心特色在于教学内容强调实战性，包含CTF（夺旗赛）挑战等模拟真实攻防场景的练习，并提供可验证的学习证书。学习路径采用结构化设计，从基础概念到工作准备形成完整闭环。用户可免费入门基础内容，通过渐进式学习体验降低初期门槛。


## 怎么赚的钱

采用免费入门+专业版订阅制：基础学习资源免费开放吸引用户；付费订阅（Pro版）解锁高级学习路径、实战项目库和可验证证书功能。当前通过Stripe实现支付验证，月收入48美元（官方披露数据），主要来自5个活跃订阅用户。未披露具体用户规模及流量数据。


## 这个案例能学到什么

① 分层变现策略：免费基础内容作为获客手段，关键进阶功能设置付费墙，既保证流量入口又明确价值锚点。② 教学内容设计：聚焦『学完就能用』的实战技能，通过CTF挑战等游戏化元素提升完课率，证书验证增强付费动力。③ 最小可行性验证：直接用Stripe接入支付系统，用真实交易数据验证需求（而非依赖流量估算），初期48美元月收入已证明模式可行性。④ 学习路径工业化：将非标技能培训拆解为标准化阶段目标，降低用户决策成本，适合复制到其他技能培训领域。注意需选择有明确能力认证需求的垂直领域（如网络安全、编程等）来复用该模式。
