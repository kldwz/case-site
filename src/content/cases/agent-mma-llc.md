# Agent MMA


## 产品是什么

Agent MMA是一个专注于综合格斗（MMA）领域的AI分析平台，主要面向格斗爱好者、赛事观众和体育媒体从业者。该产品通过机器学习技术处理比赛数据，为用户提供专业级的赛事分析，包括选手节奏控制、优势窗口期识别等传统观赛难以捕捉的深度指标。其核心功能是生成可视化数据报告和胜负预测，帮助用户更专业地理解比赛进程。使用方式为网页端服务，用户通过订阅获取定期更新的赛事分析。产品定位解决了格斗爱好者缺乏专业数据分析工具的问题，将原本需要专业团队完成的战术分析通过AI实现平民化。


## 怎么赚的钱

采用订阅制收费，具体定价档位未官方披露。根据Stripe验证数据，当前月经常性收入（MRR）为736美元，累计12个月营收6511美元。付费用户规模为58个活跃订阅，主要通过官网直接转化。


## 这个案例能学到什么

这个案例展示了三个可复用的方法论：首先，垂直领域的专业需求往往被大平台忽视，AI工具在细分场景（如体育分析）存在明确市场缺口；其次，B2C订阅模式在专业内容领域具有可持续性，通过提供持续更新的高价值分析（如每期赛事报告）能建立稳定收入流；最后，采用Stripe等轻量支付方案可快速验证商业模式，避免复杂的基础设施投入。关键启示在于：选择有专业门槛但用户付费意愿强的细分领域，用技术手段降低服务成本，通过最小可行产品（MVP）快速测试市场反应。
