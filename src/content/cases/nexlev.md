# NexLev：21 岁，自己做 20 个频道，顺手把选赛道的苦差做成工具

## 产品是什么

NexLev 是一个**给「无人出镜」（faceless）YouTube 频道主用的选赛道与运营工具**。

Faceless 频道是 YouTube 自动化圈子里的主流玩法：不出镜，用素材片段、录屏、AI 配音、动画配旁白做成视频，常见于金融科普、真实犯罪、历史、冥想、新闻评论等赛道。做这个的人通常**同时运营多个频道**，把它当资产组合来管。

NexLev 就是这个群体的工作台，包含三块：

- **Niche Finder（找赛道）**。号称分析 1.22 亿+ 频道，21 个高级筛选器，2 万+ 精选赛道，还会预测每个赛道的 RPM（千次播放收益）。
- **Chrome 扩展**。28–35+ 项功能，直接把数据叠加在 YouTube 页面上——播放量、订阅数、异常值评分叠加在视频卡片上，Shorts 信息流也能看数据，还能估算任意公开频道的月/年收入、算净利。
- **Faceless 课程 + Discord 社区**。100+ 节课、每月精选赛道点子、群教练通话。

它刻意**不做**视频生产——不写脚本、不做配音、不生成画面。它就管「选哪个赛道、值不值得做」。

## 怎么赚的钱

**订阅制分层**，价格很克制：

- **Lite**（仅扩展）：约 13 美金/月，年付 9 美金/月
- **Pro**（扩展 + Niche Finder）：约 42 美金/月，年付 30–35 美金/月
- 历史上有**终身档**：约 510 美金（Pro）、799 美金（全套含课程）
- 无免费试用，14 天退款保证

营收未公开。可见的规模信号是：Chrome 网上应用店 **10 万+ 安装**、4.0/5 分（149 票）。第三方目录称其创作者社区 **10 万+ 人、覆盖 41 国**。

## 流量从哪来

第一，**创始人本人就是圈内人**。Noah Morris 自己运营 20+ 个 faceless 频道，他做的工具首先解决自己的问题——需求不用调研，因为他每天都在痛。

第二，**公开自己的真实数据**。管多少频道、频道赚多少、怎么选赛道，都是他社媒上的内容。在一个充斥着「教你月入过万」骗子的圈子里，「我自己就在做、这是真实数字」本身就是最强的差异化。

第三，**Chrome 商店的自然搜索**。想做 faceless 频道的人第一件事就是搜工具，NexLev 卡在入口上。

第四，**第三方评测站反向导流**。aigregator、outlierkit、tubegen 这类站点都写了 NexLev 评测——包括竞品写的（tubegen 是做视频生成的，明确说「NexLev 不做生产，我们做」）。连对手都在给你带流量。

第五，**接入 MCP 生态**。NexLev 把自己的数据平台通过 MCP server 开放给 Claude、ChatGPT、Cursor 等，用户可以直接在 AI 里问 YouTube 数据问题。

## 站长是谁

**Noah Morris**，2023 年创立 NexLev 时 21 岁。

他的身份本身就是产品说明书：一个靠 YouTube 自动化谋生的年轻人，管着 20 多个频道，把自己在用的那套方法工具化。这不是「发现了市场需求」，这是「解决自己的问题顺手卖给别人」。

## 这个案例能学到什么

第一，**做你自己每天都在痛的工具，需求不用猜**。Noah 不需要做用户访谈——他就是用户，而且是最苛刻的那种（同时管 20 个频道）。

第二，**把工具做成浏览器里的叠加层**。用户不用切换工作流，数据直接长在 YouTube 页面上。降低的这点摩擦，就是留存。

第三，**窄到没人跟你抢**。NexLev 明确不服务「露脸的普通创作者」，只服务 faceless 自动化玩家。评测站直言「如果你不是做无人出镜频道的，这就是杀鸡用牛刀」——而这种「劝退」反而强化了核心用户的归属感。

第四，**公开真实数据就是最好的营销**。在这个信任稀缺的圈子里，「我自己管 20 个频道、这是真实数字」比任何广告都有效。

第五，**终身档快速回笼现金流**。510–799 美金的一次性付费，对 bootstrapped 创作者是最实用的现金流工具。
