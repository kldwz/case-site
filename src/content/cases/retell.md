# Retell AI：3 个前大厂中国人用 ~500 万美金融资做到 8000 万 ARR

## 产品是什么

**Retell AI** 是给开发者用的 AI 电话代理平台——你告诉它"客服"、"预约"、"回访"的角色，配置好知识库，**它就替你接电话、打电话**。

技术栈：实时流式 ASR（语音转文字）→ LLM（GPT / Claude）→ 流式 TTS（文字转语音）→ 自研的轮次打断模型（turn-taking）→ 接入电话网（SIP Trunk）。**端到端延迟约 600 毫秒**——已经接近真人对话节奏。

它不是 chatbot，是**真能打电话、接电话、完成业务的 agent**。从 Pine Park Health（医疗预约）到 SWTCH（电动车支持）到 Medical Data Systems（每月多收 28 万美金）——已经有真实替代 BPO 外包客服的部署案例。

## 怎么赚的钱

**完全按用量计费**，分三层：

- 语音引擎 ~$0.07–0.08 / 分钟
- LLM ~$0.003–0.08 / 分钟（按模型复杂度）
- 电信 ~$0.015 / 分钟（美国）

合计 ~$0.055 / 分钟平台费 + 模型透传成本。**比离岸 BPO（0.4–0.8 美元/分钟）便宜 70%–95%**。

订阅层 Starter $149/月起步（送 20 并发通话、10 个知识库），企业版按用量谈。营收扩张天然随客户电话量增长——客户用得越多，付得越多。

公司公开口径：**2026 年 8 月年化收入约 8000 万美金**；2024 年仅 540 万，2025 年底 4500 万，2026 年 4 月 6000 万，**8 月 8000 万**——同比增长约 650%。总融资仅约 500 万美金（种子 460 万，Alt Capital 领投，YC / Aaron Levie / Siqi Chen / Michael Seibel / Rajat Suri 跟投）。

## 流量从哪来

1. **PLG（产品驱动增长）**：开发者登录 retellai.com → 注册送 $10 免费额度 → 配一个 agent 5 分钟跑通 → 测完真打电话 → 转付费。**$10 免费试用 + $149/月起步** = 几乎零销售摩擦。
2. **行业纵深销售**：医疗、金融、保险、物流、零售——每个行业都要打电话，复用同一套引擎，**行业 know-how 比产品技术更稀缺**。
3. **YC + 创始人网络**：Bing Wu 前 ByteDance、Todd Li 前 Google、Weijia Yu 前 Meta、Evie Wang 前 ByteDance——**核心团队 5 个全是前大厂产品/工程**，前同事 + 校友 + 投资人关系是 B2B 大客户签单的隐性背书。
4. **官网案例研究**：Pine Park Health 提升 NPS 38%、Medical Data Systems 每月多收 $280K、SWTCH 客服成本降 50%——**这些数据直接打"AI 替代 BPO"的 ROI 算账**。

## 这个案例能学到什么

第一，**选被算贵了的旧成本结构当定价锚**。离岸 BPO 0.4–0.8 美元/分钟 — Retell 0.055 美元/分钟 = **便宜 70%–95%**。客户算账一目了然。**AI 产品最好打的不是"我更好"，是"对手贵了 N 倍"**。

第二，**不押单一模型**。Retell 在 ASR / LLM / TTS 每一层都接多家（OpenAI / Anthropic / ElevenLabs），**模型迭代就把你压死的事情不会发生在它身上**。OpenAI Realtime API 出来时 Retell 已经用自己拼的方案，**这就是"模型无关"的复利价值**。

第三，**自研 turn-taking = 实时语音最难的一道墙**。TTS / LLM / ASR 单独都是现成的，但拼起来要让人感觉"像人"——**关键是知道你什么时候该停、什么时候该接话**。Retell 专门自研了轮次打断模型，这是它跟很多语音 AI 拉开差距的地方。**找"行业都知道难、但没人认真做"的点深扎**。

第四，**用量计费不需要 Enterprise 天价 ARR**。传统企业 SaaS 卖 5 万–50 万美金/年的 seat license，Retell 一个月电信用量就可能过万。**用量计费 + 大客户业务量 = 比订阅制更高的 LTV**。

第五，**YC + 小融资 + 强团队也能跑大 ARR**。500 万美金总融资做到 8000 万 ARR（资本效率 ~16x），**对个人开发者或小团队来说这是一条"不靠烧钱也能长大"的路**。但前提是团队是真的懂大厂产品节奏 + 行业 know-how。
