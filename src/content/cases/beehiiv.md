# beehiiv：三个前 Morning Brew 工程师，用「不抽成」硬刚 Substack

## 产品是什么

beehiiv 是一个 **newsletter（邮件通讯）托管平台**——写作者来这发邮件订阅、管订阅者、做付费墙、接广告。

它正面刚的最大对手是 Substack。Substack 对付费订阅抽 10%，beehiiv 的招牌话术就是：**「我们不抽成。」**

不是噱头。它的逻辑是：平台靠订阅费（高级档）和自己的广告网络赚钱，而不是从创作者的收入里抠 10%。对一个月赚几千美金的独立写作者来说，「被抽 10%」年年都疼，beehiiv 把这块痛点直接拔掉。

此外它在编辑体验、增长工具（推荐、落地页、付费墙）上比老平台更现代，目标用户是「认真做 newsletter 的人」，不是随手发发。

## 怎么赚的钱

免费起步 + 付费档（按订阅规模定价），平台不抽成。另一条收入是**广告网络**——把创作者聚集起来统一接品牌广告，平台抽这部分。

账不小：**3000 万美金 ARR（2025 / 26）**，约 120 人。2024 年 3 月完成 **3300 万美金 B 轮，估值 2.25 亿美金**，NEA 领投。

5.5 万活跃用户、13 万+ newsletter 在跑。规模起来了，网络效应也开始转：创作者越多 → 读者越多 → 广告主越愿意来。

## 流量从哪来

三股：

一是**前 Morning Brew 光环**。CEO Tyler Denk 是 Morning Brew 的增长工程师——那个 newsletter 从 0 做到几百万订阅，他就在里头干增长。创作者一听「做 Morning Brew 的人来做平台了」，信任天然有。

二是**推荐计划（refer-a-creator）**：现有创作者拉新创作者进来有奖励，把创作者变成销售。三是**内容营销**——教人怎么做 newsletter、怎么涨订阅，顺手把产品卖了。

## 站长是谁

**Tyler Denk**（CEO），前 Morning Brew 增长工程师，跟 Ben Hargett、Jake Hurd 三个工程师 2021 年在纽约创立 beehiiv。

关键在：他们不是「看了 newsletter 火来凑」的外人，是**亲手把一家 newsletter 从 0 做到百万级的人**。Denk 懂增长漏斗、懂写作者卡在哪、懂平台该给什么工具——这些是从干过的行当里长出来的，抄不来。

## 这个案例能学到什么

1. **用「不抽成」正面刚对手的抽成，差异化一句话讲清。** Substack 抽 10%，beehiiv 说「我不抽」。用户一秒懂你站哪边。找差异化时，别堆功能列表，先想一句能戳对手软肋的话。
2. **从自己干过的行当里长产品。** Denk 做过 Morning Brew 增长，才来做 newsletter 平台。你最懂的行业，就是你最该创业的行业——痛点你天天疼，别人只能猜。
3. **推荐计划把创作者变成销售。** 拉新有奖励，创作者主动帮你获客。适合一切「用户之间互相认识」的社区型产品。
4. **广告网络是订阅之外的第二曲线。** 不只收订阅费，还把流量聚起来卖广告。别把收入押在单点上，平台型产品尤其要找第二条腿。
5. **先做被验证的需求，再优化体验。** newsletter 已经火了，beehiiv 不发明需求，只把体验（不抽成 + 现代工具）做得更好。创新不一定发明品类，也可以是把已验证的品类重做一遍。
